# HYP-0001 — Concentrated order-flow anomalies carry NQ entry information

- Status: proposed
- Created: 2026-07-23
- Origin idea: IDEA-0001
- Builder: Claude
- Proposed mechanism: A price level where signed volume / L1 order-flow imbalance concentrates (does not scatter) marks a level with predictive forward information, distinct from exit geometry and from rarity-filter selection on extremes.
- Exact change: Build causal L1 order-flow feature layer (CVD, OFI, touch absorption, causal volume-at-price, VWAP bands); define concentration zones causally; measure symmetric fixed-horizon forward return from those zones.
- Frozen baseline: All-bars / random-level forward return over the same session set; and the described tight-stop/wide-target bracket reported separately as geometry.
- Primary metric: Symmetric fixed-horizon forward return from causal concentration zones (per-trade, session-clustered), vs matched null distribution.
- Kill test: Symmetric forward return flat (CI includes 0) => edge is exit geometry not entry info; OR real zones inside the location-destroying null distribution => rarity filter; OR Hurst gate ablation ~0; OR fills unattainable / spread eats net under the L1 queue model.
- Required controls: Rule-15 symmetric-bracket diagnostic; Rule-16/17/18 location-destroying marginal-preserving null (compared vs distribution); Hurst with/without ablation; Rule-4 L1 queue+spread fill model; causal-only feature construction (Rule 7/8).
- Data scope: NQ RTH, 1 free Databento mbp-1 year (discovery sample, ~250 sessions; NOT a holdout).
- Multiple-testing note: Discovery sample; kill tests pre-registered before any performance run; survivors holdout-pending on future/paid data (Rule 24/26).

## Rationale and evidence

Order flow contains information the OHLCV path does not; but the described stack hits every recurring failure mode in LEARNINGS (asymmetric-bracket geometry, rarity-filter selection, Hurst-as-turnover-lever). Test the mechanism, do not clone the script.

performance interpretation until the current stage passes. This ordering is

   ⇒ the "surgical edge" is the tight-stop/wide-target geometry; stop.

   Real inside the band ⇒ rarity filter; stop.
