## Proposed mechanism

Vol-normalized, sign-asymmetric, **same-slot** percentile-rank of momentum over
several horizons (rolling window) is a regime- and time-of-day-stationary momentum
feature. A classifier maps it to a distribution over forward-return bins; trading on
`E[fwd return] = Σ_k P(k)·μ_k` (**not** the argmax bin) is the correct
decision-theoretic readout (source 1). A hysteresis (Schmitt-trigger) entry/exit band
converts churn into few, large trades so costs do not eat the edge (source 2).

## Exact change (finalized parameters)

Single-instrument pipeline on **NQ 5m RTH, decisions ≥ 10:00 ET**:

1. **Vol normalizer** `σ_day` (session scalar, known by 10:00):
   `σ_day = sqrt(α·RV_prev + (1−α)·RV_open)`, α center **0.5** (sweep {0.3,0.5,0.7});
   `RV_prev` = prior RTH session realized vol (Σ sq. 5m log-returns),
   `RV_open` = today 09:30–10:00 realized vol. Sweep alt: HAR{1d,5d,22d}+opening-30m.
2. **Feature** per horizon `n ∈ {15m,30m,60m}` (+optional 120m):
   `r̃_n = r_n / σ_day`, then **same-slot** sign-split rolling percentile rank vs the
   trailing **W prior sessions** at the same 5m slot. Composite = convex blend across
   horizons (weights center 0.5/0.3/0.2, short-favoring), per side, in [0,1].
   - Reference window **W ∈ {60, 90, 120, 252} sessions** (rolling, fixed length).
   - Coverage floor: ≥ `0.4·W` sign-consistent same-slot obs else DROP + COUNT
     (user amendment before the material run; the original 0.9 rule was infeasible).
3. **Model + readout**: classifier → `P(forward-return bin k)` over K bins
   (K center 10, sweep {5,10}); forward horizon **H = 30m** (6 bars; sweep {15,30,60}).
   Readout `E[r] = Σ_k P(k)·μ_k`, `μ_k` = **causal trailing** mean fwd-return of bin k.
   Start with multinomial/ordinal logistic or a small GBT; DNN only if justified.
4. **Execution (hysteresis)**: enter when composite (or `E[r]` rank) > `q_e` (center
   0.85), exit only when < `q_x` (center 0.55) or max-hold cap; short side symmetric.

## Frozen baselines (the ladder — build in this order)

The point is to locate where any edge lives. Each rung adds ONE thing:

| Rung | What it is | Isolates |
| --- | --- | --- |
| B0 | Flat 1-contract, always-in / buy-hold drift | the drift floor |
| B1 | Direct sign of composite same-slot rank, single threshold, next-bar open | does the FEATURE carry anything |
| B2 | B1 + **hysteresis** band (matched trade count where possible) | source 2's churn keeper |
| B3 | B2 but readout = classifier **argmax** bin | the ML adds a distribution |
| B4 | B3 but readout = classifier **`E[r]`** (expected value) | source 1's keeper |

Primary comparison for the headline: **B4 vs B1 at MATCHED trade count** (if B4 does
not beat direct ranking, the ML adds nothing — NO-GO).

## Primary metric

Per-trade mean **NET** expectancy (ticks) with **session-cluster-robust t**; plus the
**three Sharpes** (zero-day, trade-days-only, vol-targeted). **Read GROSS per-trade
FIRST** — negative gross before costs is a clean NO-GO no cost/exit tweak rescues.

## Kill tests (pre-registered — do not soften after seeing results)

1. **Gross gate**: gross per-trade ≤ 0 before costs → NO-GO.
2. **ML value gate**: B4 (`E[r]`) does not beat B1 (direct rank) at matched trade
   count → the ML is dead weight → NO-GO for the ML claim (B1/B2 may still stand).
3. **Null gate**: edge does not sit outside the distribution of a **path-preserving

4. **Sibling gate**: does not transfer in SIGN to **ES** → treat as NQ-idiosyncratic.
