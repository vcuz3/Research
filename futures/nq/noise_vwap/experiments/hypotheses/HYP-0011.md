# HYP-0011 — Volatility-conditional exit-check cadence for a fixed-1-contract prop account

- Status: rejected (EXP-0019, 2026-07-20)
- Created: 2026-07-20
- Origin idea: user question — "if the market is showing a lot of volatility we
  should not check every bar (whipsaw is likelier); do an interval check, and when
  the market is less volatile use the continuous stop."
- Builder: Claude (Opus 4.8)
- Proposed mechanism: whipsaw (transient noise touches of the band/VWAP stop that
  then recover) scales with volatility. Checking the stop every bar in a high-vol
  regime realises more of those noise touches as premature exits; checking less
  often (every 15 min) lets them pass. So route high-vol bars to a 15-min cadence
  and keep the continuous (every-bar) stop only when vol is low. Because a prop
  account capped at 1-2 micro contracts cannot pull the vol-targeting/sizing lever,
  the exit cadence is proposed as the substitute volatility lever, and the
  deployable objective is raw DOLLAR daily Sharpe at a fixed 1 contract (not the
  ATR-normalised R metric, which implicitly credits sizing down in high vol).
- Exact change: single overlay on the working baseline (lb90, 30m RTH decision
  clock, VWAP entry gate, band-or-VWAP `both` stop, next-open fills, explicit
  costs). At each bar compute a CAUSAL intraday-vol regime:
  run_range[mfo] = cummax(high) - cummin(low) from the session open to that bar,
  compared to the trailing-14-session MEDIAN of run_range at the SAME mfo
  (strictly prior sessions, shift(1); rule 9a fractional min_periods 0.7). hi-vol
  if run_range[mfo] > that median. Stop-check cadence = 15 min when hi-vol, every
  bar when lo-vol. `cond_regime`/`hivol_cadence`/`lovol_cadence` added default-off
  to core/engine2.py; None reproduces the baseline exactly.
- Frozen baseline: fixed continuous (every-bar) stop — the NQ-adopted exit. The
  conditional arm must beat always-continuous, since low-vol already uses it and
  the only claimed value-add is the high-vol interval routing.
- Primary metric: dollar (fixed-1-contract) zero-eligible-day daily net Sharpe.
  Secondary: ATR-normalised net-R daily Sharpe (reported for the rule-19 contrast).
- Kill test: REJECT unless dollar-Sharpe uplift (cond - everybar) > 0, treatment
  net$ >= baseline net$, AND the uplift beats the paired full-pipeline Null C at
  upper-tail p <= 0.05. (Standing gate: a non-positive real uplift is already a
  REJECT and does not warrant the null; run here anyway at the user's request to
  produce a complete negative-evidence record.)
- Required controls: path-preserving Null C (core/nulls via studies._null_c_frame),
  regime recomputed inside each draw so it rides the full pipeline; fixed decision
  / cad15 / everybar arms reported for context.
- Data scope: NQ primary + ES sibling, clean Databento RTH history through 2026,
  common post-lookback-90 date set. Consumed discovery sample — future shadow only.
- Multiple-testing note: one prespecified regime construction (14-session same-tod
  median split, hi->15m / lo->1m). The 5/15/30/1-min fixed cadence sweep
  (scripts/exit_cadence.py + hyp_0011_exit_cadence.py) is the motivating screen and
  is reported as consumed search; do not tune the regime threshold on this sample.

## Rationale and evidence

Motivating screen (scripts/exit_cadence.py): filling in the cadences between the
30-min decision clock and the every-bar continuous stop showed a non-monotone
interior optimum at ~15 min on the dollar metric (NQ Sh 1.14->1.29, ES 0.93->1.09).
But the fixed-15 Null C (scripts/hyp_0011_exit_cadence.py, EXP-0019 companion)
REJECTED on the canonical ATR-R metric (NQ +0.034 p=0.29; ES +0.058 p=0.19) and was
only marginal on the dollar metric (NQ +0.113 p=0.064; ES +0.120 p=0.097), with the
uplift living entirely in vol-era weighting (rule 19). This hypothesis tests whether
CONDITIONING the cadence on intraday vol — the user's whipsaw thesis — converts that
into a real fixed-1-contract edge.
