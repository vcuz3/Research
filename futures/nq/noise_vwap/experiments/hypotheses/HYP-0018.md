# HYP-0018 — Conditioning the partial-take-profit on entry-bar Hurst (bank early in chop, hold the runner in a persistent tape) beats the unconditional exit

- Status: proposed
- Created: 2026-07-22
- Origin idea: follow-on from EXP-0026 (HYP-0017). The Hurst LEVEL was shown to
  carry real, cross-market, per-trade CONTINUATION information (persistent tape ->
  higher-quality breakouts), but using it as an entry GATE failed because gating
  cuts exposure (a turnover/capacity lever, [[nq-es-crossmarket-confirm]] pattern).
  This applies the SAME confirmed signal where it costs no exposure — the exit.
- Builder: Claude (Opus 4.8)
- Proposed mechanism: a breakout entered in a PERSISTENT tape (high intraday
  Hurst H) should keep trending, so the runner should be held to the band/VWAP
  stop; a breakout entered in an ANTI-PERSISTENT / chop tape (low H) is more
  likely to snap back, so profit should be banked early. The project's one
  Null-C-surviving exit tweak — the `tp1.0_50` partial take-profit (bank 50% at
  +1 ATR, runner trails) — already monetizes real intraday MEAN-REVERSION after a
  +1 ATR extension. The hypothesis is that this mean-reversion-capture is
  concentrated in the LOW-Hurst (chop) trades and is dead weight (gives up trend)
  on the HIGH-Hurst trades. Conditioning the partial-TP on entry-H should
  therefore beat applying it to everyone or no one.
- Exact change: entry logic and trade population are UNCHANGED (every baseline
  trade is still taken — no exposure lost, no turnover lever). Only the EXIT is
  modulated. For a threshold T, a trade whose entry-bar (causal, session-to-date)
  Hurst H <= T gets the `tp1.0_50` partial take-profit (bank early); a trade with
  H > T runs to the band/VWAP stop with no partial (the baseline runner). This is
  implemented via a new default-off `tp_gate` on `core.engine2` (a set of
  (date, entry_mfo) keys where the partial fires; `tp_gate=None` -> fires on all,
  bit-exact parity with the current unconditional tp). Sweep T over
  {0.35,0.40,0.45,0.50,0.55,0.60,0.65}; the endpoints recover the two unconditional
  references (T=-inf -> no tp = continuous-stop baseline; T=+inf -> tp on all =
  unconditional `tp1.0_50`), so an interior optimum that beats BOTH endpoints is
  the conditioning value. A MIRROR control banks the HIGH-H trades instead
  (tp_gate = {H >= T}); the mechanism predicts the mirror is worse.
- Frozen baseline: NQ continuous-stop baseline — `core.session.noise_bands`
  lookback 90, RTH, 30-minute decision clock, VWAP gate, every-bar band/VWAP
  stop, next-open fills, per-instrument costs (tp OFF).
- Primary metric: full-sample zero-trade-session daily net-ATR-R Sharpe of the
  best conditional cell, with total net R co-primary. The load-bearing quantity
  is the CONDITIONING UPLIFT = Sharpe(best conditional) - Sharpe(unconditional
  `tp1.0_50`): the conditioning must beat the tp overlay it is built on, not just
  the no-tp baseline.
- Kill test: REJECT unless the best conditional cell clears daily Sharpe uplift
  >= +0.10 over the continuous-stop baseline AND net R >= baseline AND Sharpe >
  BOTH unconditional references (no-tp and all-tp) — i.e. a positive conditioning
  uplift, not just the known tp effect. If (and only if) that passes, the
  conditioning uplift over unconditional-tp must beat 30 paired drift-preserving
  Null-C draws at z >= 2, searching best-T on each draw (the return shuffle
  DESTROYS within-session persistence -> H~0.5 on the null -> the conditional
  split becomes random, so a real H-conditioning uplift must collapse on the
  null). WEAKEN if the sign does not transfer to the ES sibling, or if the mirror
  (bank high-H) is NOT worse than the conditional (bank low-H) — a mechanism this
  specific should show the predicted asymmetry.
- Required controls: (1) engine parity — `tp_gate=None` and `tp_gate`=all-entry-keys
  both reproduce the unconditional `tp1.0_50` bit-exact; (2) the two unconditional
  endpoints (no-tp, all-tp) as references; (3) the MIRROR (bank high-H) wrong-way
  control; (4) 30 paired Null-C draws with best-T re-searched per draw, only if
  the real gate passes; (5) ES sibling as the mechanism test.
- Data scope: NQ primary + ES sibling, clean Databento RTH history through 2026,
  post-lookback-90 eligible sessions. Historically CONSUMED sample — a survivor
  is at best a default-off forward-shadow candidate, never validated alpha.
- Multiple-testing note: 7-threshold sweep x {conditional, mirror}; report the
  family-max and gate the Null-C on the family-best clearing the real metric
  (standing rule [[gate-nullc-on-success-metric]]). Distinct from every prior
  filter here because it changes trade MANAGEMENT, not trade SELECTION, so it does
  not incur the exposure/turnover penalty that killed the EXP-0026 gate, the gap
  veto, KAMA, and cross-market confirm. The Null-C is a CLEANER discriminator here
  than for HYP-0011 (vol-cadence): the shuffle fully destroys the persistence the
  conditioner reads, whereas the vol-regime conditioner partly survived the shuffle
  and centered the null positive. PRIOR: cautiously optimistic — the signal is
  established real (EXP-0026), the application avoids the known death mode, and the
  Null-C mechanically zeroes on the null. Main risk: the tp partial's
  mean-reversion capture may NOT be H-selective (chop vs trend), in which case
  conditioning collapses to the unconditional tp and adds nothing.

## Rationale and evidence

EXP-0026 proved the Hurst level is a real per-trade continuation signal that does
not monetize as a selection gate (cuts exposure). The unused levers are the ones
that keep every trade; the exit horizon is the strongest because it (a) directly
expresses the confirmed mechanism (persistence -> continuation -> hold; chop ->
reversion -> bank), (b) composes with `tp1.0_50`, the only Null-C-surviving exit
tweak in the project, and (c) has a Null-C that structurally collapses because the
return shuffle destroys the persistence being conditioned on.

## Outcome (EXP-0027, 2026-07-22)

REJECTED — cross-market NO-GO; no Null-C spent (real gate fails on both). The main
risk flagged above materialized: the tp1.0_50 partial's mean-reversion capture is
NOT Hurst-selective, so conditioning the exit on entry-H adds ~nothing. Best
CONDITIONAL (bank chop / hold trend) uplift over unconditional tp1.0_50 is −0.012
Sharpe (NQ) / +0.023 (ES) — noise-level, below the +0.10 gate; at useful thresholds
it banks ~95% of trades and collapses to all-tp. DECISIVE and INVERTED: the MIRROR
(bank HIGH-H trades) is BETTER than the conditional on BOTH markets (NQ 1.354 vs
1.332; ES 0.723 vs 0.710) — the predicted asymmetry appears with the OPPOSITE sign
and transfers to ES, so it is a tiny real property, not NQ noise. Entry-bar
persistence does not predict whether a trade's post-+1ATR give-back is worth
banking vs holding. Also: the tp overlay itself helps NQ (+0.056) but hurts ES
(−0.011), so there is no robust exit surface for H to improve. Combined with
EXP-0026, the Hurst signal is real as an entry-QUALITY tag but monetizes neither
as selection nor as exit management — the Hurst exit lever is exhausted. Retain the
unconditioned baseline; keep the default-off `tp_gate` (core/engine2.py, parity
verified) as tested machinery. Evidence: `artifacts/runs/EXP-0027/review.md`.
