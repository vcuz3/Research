# HYP-0006 — A fixed early-flat cutoff before the close improves NQ risk-adjusted returns

- Status: rejected by `EXP-0013`
- Created: 2026-07-19
- Origin idea: `IDEA-0002` (paper 5095349 exit_trades_before_close, winners cluster ~30 min)
- Builder: Claude (Opus 4.8)
- Proposed mechanism: The final RTH minutes are thin and reversal-prone; flattening
  a fixed number of minutes before 16:00 ET (and taking no new entries after the
  cutoff) may reduce end-of-day giveback and drawdown without materially cutting the
  strategy's captured drift.
- Exact change: Hold the working baseline fixed (lookback 90, RTH, 30-minute clock,
  VWAP gate, every-bar band/VWAP stop, next-open fills, explicit costs) and force
  the daily flat at (16:00 ET - cutoff) instead of the last RTH bar, also stopping
  new entries after the cutoff. Grid cutoff in {15, 30, 45, 60} minutes; baseline is
  cutoff 0. Implemented default-off in the audited core/engine2.py
  (`flat_before_close`); flat_before_close=0 reproduces the baseline bit-for-bit.
- Frozen baseline: cutoff 0 (flat at the last RTH bar), otherwise the current champion.
- Primary metric: max-cell zero-trade-day daily net-ATR-R Sharpe uplift over the
  cutoff-0 baseline on the common post-lookback-90 sample.
- Kill test: Reject if the max-cell Sharpe uplift over baseline is below +0.10 on the
  primary NQ market, or (only if the real gate passes) if the corrected
  path-preserving family-max Null C upper-tail p exceeds 0.05. Materially weaken if a
  cell improves Sharpe only by cutting aggregate net R (a truncated-tail effect), or
  if the sign does not transfer to ES. Per the standing rule, the Null C is run only
  for a market whose real grid clears the +0.10 uplift and net-R >= baseline gate.
- Required controls: common sample; gross and net; trade count; top-decile
  winner-R retention (does cutting early truncate the winner tail?); daily max
  drawdown; per-era (2023+) Sharpe; ES sibling market; corrected family-max Null C.
- Data scope: primary NQ and secondary ES clean Databento RTH history through 2026;
  consumed discovery data; first 90 eligible sessions removed for every cell.
- Multiple-testing note: Four cutoffs are one prespecified family; the confirmatory
  statistic is the max-cell uplift vs the max-cell uplift from each Null C draw.

## Rationale and evidence

The paper's optimized strategies exit 11-31 minutes before the equity close, with
ladder variants clustering at 30. The paper's exact values are in-sample-optimized
and equity-margin-motivated; this test isolates the early-flat STRUCTURE on NQ/ES
futures and reports whether any Sharpe gain is real drawdown reduction or merely a
truncated winner tail, gating on a full-pipeline Null C.

## Result

Rejected by `EXP-0013`. NQ best cell (cutoff 45) ΔSharpe +0.101 clears the Sharpe
threshold but net R is −0.8 below baseline (fails the net-R gate) and maxDD is
worse; ES all cutoffs hurt (net R +51.5→+43-44, best ΔSharpe −0.030) so the sign
does not transfer. No Null C run (gate failed). The effect is NOT tail truncation
(top-decile winner-R preserved) but variance reshaping, and only on NQ. The recent
2023+ NQ Sharpe jump (1.10→1.54 at cutoffs 30-45) is a consumed-data recent-regime
observation for forward-shadow monitoring, not a historical edge. Retain
ride-to-close. See `../../artifacts/runs/EXP-0013/review.md`.
