## Mechanism

Volatility clusters and is persistent, so dispersion realised in the first 30 min
of RTH forecasts the rest of the session's realised vol. If early expansion is
high, the day will be volatile → cut size to hold risk constant (vol targeting);
if low → raise size. Monetised as improved risk-adjusted return (higher Calmar,
lower vol-of-vol) at MATCHED long-run exposure — NOT an alpha claim.

HARD CONSTRAINT (our own finding, [[nq-post-lunch-opening-range-nogo]]): morning
predicts afternoon RANGE, not DIRECTION. The ONLY permitted use is sizing /
vol-target. A directional use is a PREREGISTERED NO-GO: if the feature predicts
session sign, the construction is LEAKING future info, not carrying signal
(kill condition 3).

## Exact change

Feature `nav` (noise-area velocity): the causal expansion RATE of the open-anchored
band half-width over the first 30 min of RTH — e.g. slope of half-width vs elapsed
minutes, or `hw(open+30) / hw(open+early)` — using ONLY bars up to open+30 and
per-slot / prior-session normalised so it is scale-free, not a level (LEARNINGS
§1). Then size the deployed clock book's positions for the REST of that session by
`size ∝ target_vol / vol_hat(nav)`, where `vol_hat` is a CAUSAL forecast of
full-session realised vol fit on TRAIN only (regress session realised vol on
`nav` + prior-session realised vol, evaluated out-of-sample). `core/engine2.py`
unchanged; sizing applied in the accounting layer with explicit contract floors
and causal portfolio accounting.

## Primary metric & split

DRAWDOWN-AWARE and risk-adjusted at MATCHED long-run net exposure (so it is not a
leverage trick, RULES C/E): Calmar (net R / maxDD) and vol-of-daily-P&L vs the
flat 1-contract book. Report the THREE Sharpes (zero-day, trade-days-only,
vol-targeted — [[report-three-sharpes]]; vol-targeted is account-size sensitive).
MECHANISM CHECK (run FIRST, gates the P&L): out-of-sample R² of `nav` → session
realised vol. TRAIN first 60% / TEST last 40% of common sessions.

## Kill test (NQ TEST — ALL must hold, else REJECT)

1. `nav` has out-of-sample forecast skill for session realised vol AND ADDS over
   prior-session realised vol (the cheapest internal column, LEARNINGS §3 —
   degenerate control: score the variant that uses NO early-session info =
   prior-session vol only). If `nav` adds nothing over yesterday's vol, NO-GO
   before any P&L.
2. Vol-target sizing improves Calmar and/or reduces vol-of-vol at matched
   long-run exposure on TEST vs flat 1-contract, without materially reducing
   net R.
3. DIRECTIONAL placebo (kill condition): `nav` must NOT predict session direction
   (sign). A significant directional link ⇒ leak ⇒ investigate construction
   before any sizing claim.
4. ES TEST transfers with the same sign of forecast skill.

## Kill conditions (any ⇒ NO-GO)

`nav` adds nothing over prior-session vol; no OOS forecast skill; Calmar not
improved at matched exposure; directional leak; ES does not transfer. A wash is a
clean REJECT (rule 25).

- Sizing can manufacture Sharpe via leverage (RULES C12/13, E): match long-run
  exposure; preserve 1-contract gross/net; causal portfolio accounting with
  contract floors.

  directional edge = leak.
