# HYP-0003 — Every-bar VWAP-touch exit improves NQ risk-adjusted returns over the band-or-VWAP stop

- Status: rejected by `EXP-0010`
- Created: 2026-07-19
- Origin idea: paper 5095349 section 4.2 (the strongest exit family, VWAP-only
  exit, in-sample QQQ Sharpe up to 3.16)
- Builder: Claude (Opus 4.8)
- Proposed mechanism: The current baseline stops a position out at the tighter of
  the same-time-of-day noise band edge and VWAP (`max(band, vwap)` long /
  `min(band, vwap)` short), which gives back a position on shallow dips to the
  band (paper Figure 2). Exiting only when price crosses VWAP gives a valid
  momentum move more room to breathe, keeping the position through band dips that
  do not break the volume-weighted trend, at the cost of a larger giveback when
  the move truly fails.
- Exact change: Hold the working NQ baseline fixed — lookback 90, RTH, 30-minute
  decision clock, VWAP entry gate, every-bar exit check, next-open fills, explicit
  0.25-tick + fee costs — and change only the stop reference from `both`
  (`max(band, vwap)` / `min(band, vwap)`) to `vwap` (exit when the close crosses
  VWAP). Both arms already exist in the audited `core/engine2.py` (`stop_ref`);
  no new execution code.
- Frozen baseline: `stop_ref="both"`, lookback 90, 30m clock, VWAP gate, every-bar
  exit, next-open fills. This is the same working baseline used by EXP-0008.
- Primary metric: zero-trade-day daily net-ATR-R Sharpe uplift of the VWAP-touch
  exit over the `both` baseline on the common post-lookback-90 sample, evaluated
  against the corrected path-preserving Null C uplift distribution.
- Kill test: Reject if the observed Sharpe uplift is below +0.10, if aggregate net
  R falls below the baseline, or if the Null C upper-tail p exceeds 0.05 (the real
  uplift is not distinguishable from what the noise machinery reproduces).
  Materially weaken if the sign does not transfer to the ES sibling or if the
  next-open vs signal-close fill sensitivity exceeds the observed uplift.
- Required controls: common sample; gross and net; trade count and giveback/tail;
  per-era (2023+) delta; NQ next-open vs signal-close fill sensitivity; ES sibling
  market; corrected path-preserving Null C rerunning band construction, both exit
  arms, execution, costs, metrics, and the uplift statistic on each draw.
- Data scope: primary NQ and secondary ES clean Databento RTH history through
  2026; all history is consumed discovery data; the first 90 eligible sessions are
  removed for both arms so the comparison is on an identical sample.
- Multiple-testing note: This is a single prespecified binary change (one uplift
  statistic), not a family. The Null C compares the observed uplift against the
  distribution of the same uplift computed on each shuffled draw; there is no
  max-selection to correct because only one contrast is evaluated.

## Rationale and evidence

Paper 5095349 reports its strongest in-sample QQQ results for VWAP-based exits
(section 4.2, Table 7 VWAP #1 Sharpe 3.16), but those numbers come from a joint
Optuna optimization over the full sample with no holdout or walk-forward, so the
magnitude is not credible (see the 2026-07-18 review). This test isolates only the
VWAP-exit idea on NQ/ES futures with the working baseline otherwise frozen and
gates it on a full-pipeline Null C, exactly as the exit-management work
(`tp1.0_50`) was gated.

## Result

Rejected by `EXP-0010`. NQ uplift ΔSharpe −0.031 (fails the +0.10 gate), Null C
p=0.8710; ES uplift ΔSharpe +0.258 but Null C p=0.2903 with a null-uplift mean of
+0.178. The looser VWAP-only stop reduces trade count ~27% and raises per-trade
net R, but that same mechanism lifts Sharpe as much or more on path-preserving
noise, so it is a variance/selectivity amplifier, not exit information. Fill
sensitivity negligible on both arms. Retain the `both` stop. See
`../../artifacts/runs/EXP-0010/review.md`.
