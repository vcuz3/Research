# HYP-0001 — A short causal noise lookback improves NQ risk-adjusted returns

- Status: rejected by `EXP-0008`
- Created: 2026-07-18
- Origin idea: IDEA-0001
- Builder: Codex
- Proposed mechanism: A 2-14-session strictly-prior same-time-of-day noise estimate adapts faster than 90 sessions to the current volatility regime, improving breakout timing.
- Exact change: Hold the RTH 30-minute VWAP-gated next-open engine and every-bar band/VWAP stop fixed; change only noise lookback across the prespecified family 2,4,5,8,14,30,60,90 on a common post-90-session sample.
- Frozen baseline: NQ working baseline: lookback 90, RTH, 30-minute decision clock, VWAP entry gate, every-bar band/VWAP stop, next-open fills, explicit 0.25-tick plus fee costs.
- Primary metric: Maximum zero-trade-day daily net-ATR Sharpe uplift over lookback 90, evaluated against the full-family Null C maximum-statistic distribution.
- Kill test: Reject if the selected short lookback has Sharpe uplift below +0.10, lower aggregate net R than lookback 90, or family-wise Null C p-value above 0.05; materially weaken if 2023+ delta is negative or ES transfers with the opposite sign.
- Required controls: Common sample; gross and net; trade count and top-tail retention; per-era deltas; NQ next-open versus signal-close sensitivity; ES sibling market; corrected path-preserving Null C rerunning band construction, all candidates, execution, costs, metrics, and selection.
- Data scope: Primary NQ and secondary ES clean Databento RTH history through 2026; all history is consumed discovery data, with the first 90 eligible sessions removed equally for every candidate.
- Multiple-testing note: Eight lookbacks are one prespecified family. Compare observed max Sharpe uplift with the maximum uplift selected from each repeated full-pipeline Null C draw; do not interpret unadjusted cell p-values.

## Rationale and evidence

The source paper reports that all optimized winners used 2-8 day lookbacks, but its evidence is a 2014-2024 QQQ in-sample optimization without reported walk-forward or sealed holdout validation. This test isolates the claim in futures without importing the paper's optimized exits or sizing.

## Result

Rejected. NQ's selected nonbaseline lookback was 30, with Sharpe uplift -0.065,
net-R delta -3.8, and family-wise Null C p=0.8571. ES selected lookback 2, but
its Sharpe uplift was only +0.026 with p=0.1905. See
`../../artifacts/runs/EXP-0008/review.md`.
