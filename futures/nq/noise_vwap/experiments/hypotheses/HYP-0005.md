# HYP-0005 — A narrower noise exit band plus a looser VWAP-sigma band improves NQ risk-adjusted returns

- Status: rejected by `EXP-0012`
- Created: 2026-07-19
- Origin idea: `IDEA-0004` (paper 5095349 s.4.3/4.4, different entry & exit boundaries)
- Builder: Claude (Opus 4.8)
- Proposed mechanism: A separate, wider-room exit boundary lets a valid breakout
  breathe through shallow dips to the noise band (paper Figure 2) instead of being
  stopped and re-entered, while still cutting a genuine failure. The exit stop is
  the looser of a narrower noise band (multiplier s < 1 = closer to the reference,
  so a long re-enters the noise area only after falling further) and a VWAP band
  offset below price by y volume-weighted stds.
- Exact change: Hold the working baseline entry fixed (lookback 90, RTH, 30-minute
  clock, VWAP entry gate at the multiplier-1.0 band, next-open fills, explicit
  costs). Replace only the stop with:
  - long:  exit when close < max( ref_hi*(1 + s*sigma),  VWAP - y*sigma_vw )
  - short: exit when close > min( ref_lo*(1 - s*sigma),  VWAP + y*sigma_vw )
  where sigma is the same-time-of-day noise, ref_hi/ref_lo = max/min(open,
  prior_close), and sigma_vw is the per-bar causal cumulative volume-weighted std
  of typical price about VWAP (core.vol_bands.vwap_sigma_bands definition). Grid
  s in {0.5, 0.75}, y in {0.5, 1.0} (y positive = VWAP leg BELOW price for a long,
  i.e. looser). Implemented default-off in the audited core/engine2.py
  (`exit_bands`, `exit_y`); exit_band with s=1.0, y=0 reproduces the `both`
  baseline bit-for-bit (verified).
- Frozen baseline: current champion `stop_ref="both"` every-bar band/VWAP stop.
- Primary metric: max-cell zero-trade-day daily net-ATR-R Sharpe uplift over the
  `both` baseline across the s x y grid, on the common post-lookback-90 sample.
- Kill test: Reject if the max-cell Sharpe uplift over `both` is below +0.10 on the
  primary NQ market, or (only if the real gate passes) if the corrected
  path-preserving Null C family-max upper-tail p exceeds 0.05. Per the standing
  rule, the Null C is run only for a market whose real grid clears the +0.10
  uplift and net-R >= baseline gate.
- Required controls: common sample; gross and net; trade count; per-era (2023+)
  Sharpe; ES sibling market; corrected path-preserving family-max Null C rerunning
  band construction, sigma_vw, all cells, execution, costs, metrics, and the
  max-cell statistic on each draw (for any market that passes the real gate).
- Data scope: primary NQ and secondary ES clean Databento RTH history through
  2026; consumed discovery data; first 90 eligible sessions removed for every cell.
- Multiple-testing note: Four exit-band cells are one prespecified family; the
  confirmatory statistic is the max-cell uplift compared against the max-cell
  uplift from each full-pipeline Null C draw. The literal negative-y version (VWAP
  leg above price) was run first and rejected on both markets; this positive-y
  version is the user-selected intended test, not an additional search of the same
  family.

## Rationale and evidence

Paper 5095349 s.4.3/4.4 allows a narrower exit boundary than the entry boundary.
The paper's numbers are in-sample-optimized (see the 2026-07-18 review), so this
test isolates the STRUCTURE — a separate, roomier exit boundary — with entries
frozen and gates it on a full-pipeline Null C, and only for a market that first
clears the real success metric.

## Result

Rejected by `EXP-0012`. Flipped/looser grid: NQ best cell `s0.75_y1.0` ΔSharpe
+0.090 / ΔnetR +14.1 FAILS the +0.10 gate (no null run per the standing rule); ES
best `s0.5_y0.5` ΔSharpe +0.320 PASSES the real gate but the family-max Null C
reproduces a +0.254 mean uplift on noise (p=0.2903). The literal negative-y grid
was rejected on both markets first. The looser exit is a variance/selectivity
amplifier (fewer trades, higher per-trade R) — a turnover/capacity lever, not
alpha. Retain the `both` stop and `tp1.0_50`. See
`../../artifacts/runs/EXP-0012/review.md`.
