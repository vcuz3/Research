# HYP-0010 — ES cross-market breakout confirmation gates NQ noise-VWAP entries

- Status: proposed
- Created: 2026-07-19
- Origin idea: none
- Builder: Claude (Opus 4.8)
- Proposed mechanism: NQ and ES are tightly coupled equity indices, so the "noise area" carries shared information. A real breakout should appear on BOTH indices simultaneously; an NQ break with no contemporaneous ES break is idiosyncratic noise outside the noise area. Gating NQ entries on ES confirmation should therefore retain the informative breaks and drop the noise ones.
- Exact change: Single-variable overlay on the frozen faithful NQ baseline. At each NQ decision (date, tod) read ES's contemporaneous state from ES's own bars / cumulative RTH VWAP / 90-session noise bands (same audited code path). Variants: agree (PRIMARY: take NQ signal only if ES broke out the same way), gate (ES in any breakout), vwap (take NQ signal only if ES is on the same side of its own VWAP — the "don't go long if ES is under its VWAP" form), es_dir (enter NQ in ES's direction), es_opp (mirror-trap check), disagree (GC's weak-survivor control). Entries/exits/flips/fills otherwise identical to baseline.
- Frozen baseline: NQ faithful baseline: lookback 90, RTH, Concretum :59/:29 30-minute decision clock, VWAP entry gate, band-or-VWAP (`both`) stop, next-open fills, 1 contract. Run on the common NQ∩ES date set.
- Primary metric: Net daily Sharpe uplift of the PRIMARY (agree) variant over the common-set baseline; gross-per-trade on the KEPT trades reported alongside as the rarity-filter discriminator.
- Kill test: Reject unless the agree variant lifts net daily Sharpe by >= +0.05 over the common-set baseline. If agree fails but a secondary variant clears +0.05, null that one but label it post-hoc/secondary (family of 6, consumed history). If the gate passes, the uplift must beat the re-pairing null at z>=2 with frac(null>=real)<0.05.
- Required controls: Re-pairing null (Rule 18) — pair each NQ session with a random OTHER ES date's state series (same tods), donors stratified by calendar year, >=200 draws; destroys contemporaneous cross-information while preserving each leg's own dynamics. The null's CENTER is the discriminator (~0 = real cross-info; ~=real uplift = rarity filter). es_opp is the mirror-trap check (Rule 16). Read gross-per-trade on kept trades, not just Sharpe.
- Data scope: NQ primary and ES confirmer, clean Databento RTH history through 2026, common post-lookback-90 date set; historically consumed discovery sample.
- Multiple-testing note: agree is the single preregistered primary (the user's stated thesis). gate/vwap/es_dir/es_opp/disagree are secondary diagnostics; a secondary Sharpe survivor is a post-hoc family-of-6 result, holdout-pending, not the stated thesis.

## Rationale and evidence

Direct precedent is GC HYP-0005/EXP-0007, which conditioned GC direction on the contemporaneous ES noise-VWAP state and found the agree filter was a rarity filter that HALVED gross-per-trade (selecting worse trades), while a disagree filter was a marginal, re-pairing-null-centered-at-0 weak survivor. NQ↔ES are far more tightly coupled than GC↔ES, so the user's shared-information premise is more plausible here and worth an independent test with the same re-pairing-null discipline.
