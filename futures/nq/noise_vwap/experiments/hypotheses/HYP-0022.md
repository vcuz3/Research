## Mechanism

The 1m continuous stop is close-confirmed: a bar must CLOSE beyond
`stop = max(upper, vwap)` (long) to exit. EXP-0031 showed this is a wick filter —
a tolerance against intrabar noise — but an arbitrary one, pinned to the 1-minute
sampling grid (unbounded intrabar, zero at the close). Replace it with an explicit,
volatility-scaled buffer: exit on the first 1s touch of
`stop(t) = max(upper, vwap) − k · ATR_N(t)` (long; `+` for shorts), where
`ATR_N(t)` is a CAUSAL rolling mean of 1-min True Range over the last `N`
completed minutes (`shift`ed so only completed bars are used). The stop floats:
it is recomputed every minute from the completed prior bar (matching the current
continuous stop), no ratchet. Entries are UNCHANGED (single variable = the exit
buffer). Thesis: intraday noise wicks scale with recent intraday ATR, so a
`k·ATR_N` buffer filters noise proportionally and systematically, trading the
sampling-frequency artifact for a tunable, vol-aware tolerance.

## Exact change

- New causal intraday ATR: `TR_t = max(high−low, |high−prev_close|, |low−prev_close|)`
  over 1-min RTH bars within the session; `ATR_N` = rolling mean over `N` completed
  bars. Available from the first possible entry (decision clock first fires at
  mfo 30), so `N ≤ 30`.
- New buffered-stop 1s first-touch kernel (`core/atr_buffer.py`); the existing
  audited `core/first_touch.py` kernel is untouched. `k = 0` reduces to the
  EXP-0031 first-touch stop bit-exactly.

## Primary metric

Zero-eligible-day one-contract daily net Sharpe at 0.5 tick/side + $2.25 fees, on
the common post-lookback-90 NQ RTH sample, versus the two anchors: the 1s
first-touch `k = 0` (0.883) and the close-confirmed continuous stop (0.923).

## Kill test / gate (preregistered)

Phase 1 is exploratory and answers three questions in order:

1. **Does any (N, k) cell beat close-confirmation (0.923)** on daily Sharpe WITHOUT
   collapsing net R or worsening maxDD? If the best cell merely reproduces 0.923,
   the win is that we have SYSTEMATIZED the arbitrary mechanic (now sampling-
   independent and tunable), not beaten it.
2. **Is the vol-scaling load-bearing?** Compare the best ATR cell against a
   FIXED-POINT buffer of matched median exit-width (EXP-0021 RAW-vs-MATCHED
   method). Reject the scaling claim if fixed ≈ scaled at matched width (then the
   ATR is only a width/turnover dial).
3. Calibrate `k` from the data: the depth (in ATR_N units) of the recovered wicks
   close-confirmation tolerates vs the depth of real breakdowns. A separated
   distribution predicts `k*`; the sweep should confirm it.

Phase 2 (Null C + ES) is spent ONLY if Phase 1 clears (1) with the scaling
surviving (2) — per the standing "gate Null C on the success metric" rule. A
looser stop mechanically reduces exits, so a Sharpe rise is treated as variance
amplification until a path-preserving Null C (read the null-center sign) and the
ES sibling confirm the effect is real and not machinery.
