## Question / mechanism

The EXP-0038 per-cell daily-$ Sharpe profile (high-vol cells ~1.8-2.3, elevated-vol
cells ~0.1-0.45) is a DESCRIPTIVE stratification of realised P&L. The strategy's
exploitable content is intraday TIMING (does the tape continue after a band+VWAP
breakout). The drift-preserving Null C (`core/nulls.py::null_c_returns`) destroys
that intraday order while preserving each session's opening anchor and NET move --
so it preserves daily close-to-close returns and therefore the vol/trend regime
LABELS exactly, but destroys the intraday continuation the strategy trades.

If the high-vol Sharpe concentration is real, exploitable timing information, the
real per-cell Sharpe must exceed the null's per-cell Sharpe IN THAT CELL. If instead
the concentration is vol-geometry / clustering the null reproduces (the EXP-0017/0019
signature), real ~ null within the cell -- and there is nothing for a vol gate or a
vol-conditioned size to capture, because the "good" cells are good on noise too.

## Exact change

No strategy change. Re-run the EXP-0038 stratification on N drift-preserving null
draws. Per draw, per variant, per (vol x trend) cell and per marginal axis, record
the zero-day daily-$ Sharpe (1 contract, 0.25 tick/side), using the REAL (preserved)
regime labels. Compare the real per-cell Sharpe to the null distribution.

Three variants, each on its own audited null pipeline, same seed sequence:
- baseline   : `core.engine.run(null_c_returns(load_rth), bands, every_bar)`
- atr_buffer : `run_1m_atr(null_c_returns(load_rth), bands, N20_k1.5)` (1m proxy,
               the EXP-0033/0037 null path)
- partial_tp : `engine2.run(_null_c_frame(load_session), bands, dm, every_bar,
               tp1.0_50)` (the exit_mgmt.run_null path; recomputes ATR on the
               shuffled path)

## Primary metric

Per variant: per-cell real Sharpe vs null-mean Sharpe, z = (real - null_mean)/null_sd,
and frac(null >= real). Aggregate daily Sharpe real vs null as the anchor (baseline is
already a known Null-C pass, MEMORY z~5.2). Rule 17-bis diffusivity gate reported
(null median vs real).

## Kill test / decision rule

- If the HIGH-VOL cells' real Sharpe sits inside their null band (frac >= ~0.15, z low)
  -> the high-vol concentration is null-preserved vol-geometry, NOT exploitable timing.
  Conclusion: a vol gate and a vol-conditioned SIZE are both dead on arrival (they
  reweight toward cells that are equally good on noise). Do NOT build either; the
  regime finding is a monitoring/drawdown-coverage fact only. This is the expected
  outcome.
- If the high-vol cells' real Sharpe DECISIVELY beats null (frac < 0.05 across draws,
  and by more than the aggregate does) AND the elevated-vol dip is real (real < null
  there) -> the vol dependence is real, exploitable structure. ONLY THEN promote a
  preregistered CAUSAL vol-sizing test (expanding/rolling-quantile thresholds known at
  decision time; monotonicity + era-stability of the elevated notch first).

## Controls

- Regime labels are preserved by the null (open pinned + net move preserved -> daily
  closes preserved); asserted equal to real on draw 0. So the null and real are
  stratified by IDENTICAL cell membership -- the comparison isolates timing content
  within a fixed regime, not a relabelling.
- Three variants sharing identical entries: a real vol-timing effect should show in
  all three; an exit artifact would not.
- Diffusivity gate (rule 17-bis) per draw.
- Aggregate Null C as the sanity anchor (must reproduce the known baseline pass).
