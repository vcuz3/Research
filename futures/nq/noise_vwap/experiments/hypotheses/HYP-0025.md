# HYP-0025 — Volatility Expansion Index (intraday short/long ATR ratio) entry gate

- Status: rejected (EXP-0035 SMA + EXP-0036 Wilder-RMA revisit; NO-GO both markets)
- Created: 2026-07-26
- Origin idea: user request — investigate the "volatility expansion index" (intraday
  short-lookback ATR / long-lookback ATR, baseline ATR10/ATR50, plus other variants)
  on NQ and then on the noise-VWAP strategy.
- Builder: Claude (Opus 4.8)
- Proposed mechanism: VEI = intraday ATR(short)/ATR(long) measures the ACCELERATION
  of within-session volatility (vol-of-vol / regime change), distinct from the RVOL
  LEVEL (EXP-0015/0016) and the daily ATR scale. Naive thesis: a breakout that fires
  while vol is EXPANDING (VEI high) has real impulse and follows through; a breakout
  in a CONTRACTING tape fails. Part-1 exploration (EXP-0035) INVERTED that sign: at
  the breakout signal, VEI is NEGATIVELY related to continuation-to-close (baseline
  10/50 IC −0.030, CI [−0.046,−0.015]; same negative sign on all five variants). So
  the mechanism under test is the CORRECTED one — a breakout out of a low-VEI
  COMPRESSION/coil continues better than a high-VEI late chase — evaluated as an entry
  gate keeping LOW-VEI breakouts.
- Exact change: per-signal entry gate (rule 18, engine rerun via `entry_gate`), open
  only at decision keys whose causal VEI is >= T ("high") or <= T ("low"); sweep T
  over VEI quantiles {0.2..0.8} across variants (short,long) in {(5,20),(10,50),
  (10,100),(14,50),(20,100)}. Entries/exits otherwise unchanged. VEI computed in
  `core/vei.py` (causal within-session rolling-mean True Range; strict min_periods,
  coverage reported per rule 9a).
- Frozen baseline: continuous-stop NQ/ES baseline — noise_bands lb90, RTH, 30-min
  decision clock, VWAP gate, every-bar band/VWAP stop, next-open fills, per-instrument
  costs (`core.engine2`/`engine2_nb`).
- Primary metric: full-sample zero-trade-day daily net-ATR-R Sharpe uplift over
  baseline at the family-best filtering cell; net R co-primary (must be >= baseline).
- Kill test: family-best fails dSharpe >= +0.10 AND netR >= baseline ⇒ REJECT from
  real evidence (no Null C spent, standing rule). If it passes: (1) matched-count
  random-signal-drop null must show real beats a random equal-count keep
  (frac(rand>=real) < 0.05) — else it is a rarity/turnover lever; (2) paired
  drift-preserving Null C must clear (real > null center, p <= 0.05) — else it is
  path/vol-geometry machinery the null preserves (the EXP-0010/0012/0019/0032
  signature). Cross-market ES must reproduce the sign.
- Required controls: matched-count random-drop null (always, on family-best);
  drift-preserving Null C (gated); ES cross-market; both gate directions
  (high/low) so a wrong-signed selection is visible; net R read alongside Sharpe
  (a Sharpe held only by a trade-count collapse with gross/trade falling is a rarity
  filter — the [[nq-es-crossmarket-confirm]] pattern).
- Data scope: NQ and ES clean Databento RTH 1-min, 2011–2026, common post-lb90
  sample. Consumed research history — not a sealed holdout.
- Multiple-testing note: family = 5 variants × 2 directions × 7 thresholds = 70 cells
  per market; family-best is a searched maximum, so the Null C (when run) repeats the
  selection. Priors are strongly against monetization: the noise-VWAP edge is
  volatility-INDEPENDENT and every prior selectivity screen (RVOL EXP-0016, gap
  EXP-0024, Hurst EXP-0026/0027, ATR-buffer EXP-0032) resolved as a turnover/capacity
  lever, not alpha.

## Rationale and evidence

See EXP-0035 `review.md`. Part 1 (`vei_explore.py`) establishes VEI's descriptive
predictive value on NQ: near-zero directional IC, weak positive magnitude IC (vol
clustering), and a small but cross-variant-consistent NEGATIVE breakout-continuation
IC (low VEI = better follow-through). Part 2 (`hyp_0025_vei_filter.py`) tests whether
that entry information monetizes as a gate.

## Verdict (EXP-0035)

REJECTED — NO-GO on both NQ and ES. Part 1: VEI predicts forward magnitude weakly
(vol clustering) not direction; the breakout-continuation IC is small/negative on NQ
(low-VEI = better follow-through) but weak/insignificant/sign-flipped on ES (does not
transfer). Part 2: the entry gate fails the real gate on both markets — NQ every cell
negative dSharpe (pure exposure cut), ES +0.066 Sharpe but net R falls and it is a
turnover lever indistinguishable from random dropping, direction opposite to NQ. No
Null C spent (standing rule). Consistent with volatility-INDEPENDENCE. See
`artifacts/runs/EXP-0035/review.md`.

## Wilder-RMA revisit (EXP-0036, 2026-07-26)

User asked to retry with the RMA (Wilder) VEI variant, which `vei_exploration` Study A
showed is far cleaner than the SMA used in EXP-0035. Result: NO-GO but sharper. The
cleaner estimator moved the NQ gate from clear-fail to real-gate PASS — family-best
VEI(5/20) `low`≤1.003 (keep low-VEI/coiled breakouts, drop the highest-VEI ~15% late
chases): dSharpe +0.105, net R flat +0.33, retain 0.855 — and it BEATS the matched-count
random-drop null decisively (frac 0.000) = real per-trade quality selection (matches
EXP-0035 Part-C). BUT it fails the decisive drift-preserving Null C on the primary metric
(dSharpe real +0.105 vs null mean −0.001, z+0.90, frac(null≥real)=0.175; dNetR frac 0.40)
and does NOT transfer to ES (best cell cuts 62% of trades, net R −12.0 = turnover lever).
So: a real, weak per-trade tilt (low-VEI breakouts are better), not validated alpha — the
low-VEI quality selection is largely reproduced once returns are shuffled (vol-geometry
the null preserves). Estimator is load-bearing; verdict unchanged. Evidence:
`artifacts/runs/EXP-0036/`.
