# HYP-0021 — Multi-horizon percentile-ranked breakout strength with hysteresis improves NQ

- Status: proposed
- Created: 2026-07-22
- Origin idea: none
- Builder: Codex
- Proposed mechanism: Noise-VWAP breakouts with unusually strong momentum across several horizons should persist; a lower exit threshold should ignore small reversals and reduce churn.
- Exact change: At every minute, rank causal ATR-normalized returns over 5/15/30/60-minute horizons against strictly prior same-minute-of-session, same-sign observations; average available ranks. Gate normal 30-minute-clock entries at q_enter, and for the hysteresis arm permit the existing continuous band/VWAP stop only after the active-side composite falls below q_exit. Flips and EOD remain unchanged. Compare rank-only and rank+hysteresis arms.
- Frozen baseline: Frozen NQ lb90 noise-band, VWAP-gated, 30-minute entry clock, next-open fills, every-bar band/VWAP stop.
- Primary metric: Family-best zero-trade-day daily net-ATR-R Sharpe uplift with total net R co-primary.
- Kill test: Reject unless family-best NQ dSharpe >= +0.10, net R >= baseline, and kept-trade gross expectancy rises; if cleared, require family-max paired Null C z>=2 and frac(null>=real)<0.05. Weaken if improvement is only reduced exposure/turnover or fails ES directional transfer.
- Required controls: Baseline parity; rank-only versus hysteresis interaction; inverted weak-rank gate; matched-count random signal retention; turnover/holding-time decomposition; same-time-of-day coverage audit; paired path-preserving Null C only after real gate.
- Data scope: NQ primary clean Databento RTH 2011-2026 post-lb252 common sample; ES sibling only if NQ real gate clears or for sign discrimination. Entire history consumed.
- Multiple-testing note: Small frozen q_enter x q_exit family; select family maximum and rerun complete selection under Null C.

## Rationale and evidence

Tests the main reusable mechanism from the percentile-rank momentum paper while isolating it from already-rejected noise-band quantile reshaping.
