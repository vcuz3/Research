## Question / mechanism

If the intraday edge is genuinely larger (risk-adjusted) in high-vol regimes, then
OVERWEIGHTING high-vol days should raise the aggregate risk-adjusted return -- unless
the extra concentration into the high-vol drawdown regime worsens tail/drawdown enough
to negate it (the EXP-0028 failure mode). Test a CAUSAL vol-regime size overlay and
decide with its own Null C plus an explicit drawdown read.

## Exact change (all causal, rule 7/12)

Signal: causal trailing-20d annualised realised vol, shifted 1 session (`build_regimes`
`rv_ann`, decision-time-known). Its causal EXPANDING percentile `q_d` (rank of `rv_d`
vs STRICTLY-PRIOR `rv`; neutral weight until 252 prior obs).

Schedules (raw weight, then normalised by the causal expanding PRIOR mean so average
exposure ~= 1 contract -- EXP-0017 protocol, no net-leverage artifact):
- PRIMARY `high_boost` : w = 1.0 if q < 0.75 else 1.5  (boost only high vol -- matches

- CONTROL `vol_down`    : w = 1.5 - 1.0*q               (mirror; must be WORSE if real).

Two frames:

Because the drift-preserving null preserves daily returns EXACTLY (EXP-0039, asserted),
`w_d` is IDENTICAL real-vs-null; the null therefore isolates whether the uplift comes
from real intraday edge concentrated in high vol, or from variance reshaping the null

## Primary metric

Frame A: daily-$ Sharpe uplift (sized - unsized) at 1x-mean exposure; AND max $
drawdown change and 5% daily CVaR change. Null C over 40 drift-preserving draws:
z and frac(null >= real) for the Sharpe uplift; same for the drawdown change.

## Kill test / decision rule

- GO-candidate (-> forward shadow, NOT capital): PRIMARY `high_boost` Frame-A Sharpe
  uplift beats null decisively (frac < 0.05) AND max drawdown does NOT materially
  worsen (dMaxDD not worse than a small tolerance, and CVaR not worse) AND `vol_down`
  mirror is worse (sign check).
- NO-GO: uplift inside the null band (frac >= ~0.15 -> variance reshaping, EXP-0017
  signature); OR Sharpe uplift is real but bought entirely with worse drawdown/tail
  (the EXP-0028 tail-concentration failure) -> not deployable as a risk improvement.
