# HYP-0026 — ATR-buffer family under volatility-cluster-preserving block-permutation Null C

- Status: REJECTED (EXP-0037). All 5/10/15-minute block nulls reproduce the
  family-selected ATR-scaling uplift; none approaches the frozen gate.
- Created: 2026-07-26
- Origin idea: user request to preserve local volatility clusters in Null C
- Builder: Codex
- Proposed mechanism: The one-minute atom shuffle may be too destructive for an
  ATR-scaled exit because it breaks local volatility sequencing that the exit is
  designed to follow. Permuting contiguous 5-, 10-, or 15-minute blocks preserves
  within-block volatility clusters and micro-trends while destroying their broader
  time-of-day placement and multi-hour order.
- Exact change: Pin only the artificial opening-link atom, partition every later
  atom into contiguous non-overlapping k-minute blocks, and randomly permute all
  blocks including a possibly shorter terminal block. Preserve order inside every block and rebuild price,
  VWAP, the 90-session bands, causal ATR, and the complete ATR-buffer family.
- Frozen baseline: EXP-0033 one-minute selection-corrected Null C and EXP-0032 real
  ATR-buffer family; N in {5,10,14,20,30}, k in {0.25,0.5,0.75,1.0,1.5,2.0}.
- Primary metric: For each block size, family-selected zero-trade-day daily net
  Sharpe uplift of the scaled ATR buffer over its selected cell's matched fixed-width
  buffer. Uplift over close-confirmed is secondary.
- Kill test: The ATR-scaling claim remains rejected unless the real family-selected
  scaling uplift exceeds every block-null distribution with finite-sample upper-tail
  p<=0.05, z>=2, and a non-positive null center. Because three block sizes are tested,
  require this result for all three rather than selecting the most favorable block.
- Required controls: 199 deterministic draws per block size; repeat the complete N-k
  maximum-Sharpe selection in every draw; same costs/accounting; anchor, atom, volume,
  net-move, diffusivity, within-block-order, and deterministic-seed tests; report
  lag-1/lag-k dependence and time-of-day profile destruction for each block size;
  compare directly with the EXP-0033 one-minute null.
- Data scope: NQ clean one-minute Databento RTH through 2026-07-14; consumed history.
- Multiple-testing note: Selection across the full N-k family is repeated inside
  each draw. The three requested block sizes are separate robustness requirements;
  no best-block selection is allowed.

## Rationale and evidence

This is a stricter alternative null specification for the already rejected ATR-buffer
claim, not a new strategy search. A block null is expected to retain more short-run
volatility dependence than the one-minute atom null; whether that materially shifts
the null center is the question being tested. A pre-run validation rejected the first
draft policy that pinned the entire opening block because it retained too much original
time-of-day structure (absolute-body profile correlation 0.50/0.60/0.66 for 5/10/15m);
the frozen material-run policy therefore pins only the mandatory opening atom.
