## Preregistered protocol

1. Load NQ common sessions; split by session index: TRAIN = first 60%, TEST =
   last 40%. The engine runs once over full continuous history (bands warm up
   across the boundary); each era is scored by subsetting `dates`.
2. On **TRAIN only**, run the exit-only overlay at h in {1,2,3} and select
   `h* = argmax` TRAIN exit-only dSharpe. Freeze h*.
3. Evaluate on **NQ TEST**:
   - baseline vs exit-only(h*) dSharpe and dNetR (real gate: dSharpe>=+0.10 AND
     netR not fall);
   - `same` (inverted) and `fixed` (blind delay, calibrated to the real arm's mean
     achieved delay) arms;
   - random-release null, hazard bisected to the real arm's TEST trade count,
     RAND_DRAWS=200 (frac(random>=real)<0.05);
   - fill ablation next_open vs signal_close (uplift must survive next_open);
   - coverage (drops + achieved delay).
4. Kill test on NQ TEST (ALL must hold): real gate, beats_random, beats_fixed,
   beats_same, survives_next_open.
5. If 4 passes, run drift-preserving Null C on the NQ TEST bars and require ES
   TEST transfer with the same-sign gate. Otherwise Null C is skipped (standing
   project gate rule).

## Rationale and priors

Same priors as HYP-0034 apply (random-exit equivalence in FX; EXP-0043 control 1b;
shared-close/touch-vs-fill; quality-not-alpha turnover levers). The specific new
risk here is selecting the horizon from a sweep already run on the full sample; the
TRAIN/TEST split and the frozen-before-TEST discipline address the selection, and the
null battery addresses machinery/fill artifacts. A wash or negative TEST gate is a
clean REJECT.

## Post-hoc note (2026-08-16)

NO-GO confirmed, for a SELECTION reason. A follow-up mechanism study
(`reports/POST_STOP_REVERSION.md`) first over-stated this as "no reversion exists"
(contradicting the paper); corrected by re-analyzing on the adverse-run-length axis.
Short-term reversion IS real and run-length-monotone on all bars (paper replicates),
but tiny in tradable R units (~0.003 R gross, sub-cost standalone). At our stops the
run-length monotonicity vanishes (NQ run≥5 ≈ 0; ES insignificant) because a run strong
enough to break the band+VWAP stop is a continuation-selected case — there is no
run-length STRUCTURE to key on. **Second correction (same day):** the first draft of
this note called the blind-delay>random gap "exposure/variance"; a Shapley decomposition
disproves that (+117% MEAN / −17% variance). The blind fixed 4-bar delay DOES capture a
small, real, cost-surviving post-stop reversion (+0.0041 R/trade net, +6.6 R over TEST) —
more than the paper's sign rule. So the REJECT is precisely of the paper's fast-alpha
SIGN mechanism (a blind delay dominates it); a blind stop-delay itself is a small real
reversion capture that weakens the stop (maxDD +22%, fatter tail) and is a separate,
drawdown-gated OPEN lead, not part of this NO-GO. See `reports/POST_STOP_REVERSION.md`
§Decomposition and `artifacts/runs/EXP-0047/review.md` Addendum 2.
