## Origin (SEARCHED discovery — rule 26)

Two 2026-08-16 diagnostics, both extending the fast-alpha work
(`nq-fast-alpha-overlay-nogo`):

1. **NQ non-stationarity decomposition** (`scripts/diag_nonstationarity.py`): the NQ
   2024→2026 fade is a HIT-RATE / follow-through collapse (win% 27.9→25.8→20.8%, 2026
   below the ~23% geometric break-even for a 3.3:1 payoff), NOT fewer signals
   (trades/session ROSE to 1.35), NOT shrinking winners (win/loss magnitude ratio
   ~stable 3.97→3.31), NOT variance (dStd flat). Recent breakouts increasingly fail to
   follow through = more false/shallow breaks.
2. **Anticipatory-entry sweep** (`scripts/sweep_entry_buffer.py`): per-trade net edge is
   MONOTONE in break depth — entering EARLIER than the band (front-running) strictly
   destroys edge; requiring a DEEPER break monotonically raises per-trade net points, and
   MORE so in the recent (TEST) era (NQ deeper-break +0.1ATR net-pt 3.32 TEST vs 1.61
   TRAIN). The market pays for confirmation, not anticipation.

These rhyme: shallow breakouts fail more recently, so a **confirmation-depth entry gate**
(require the decision-bar close to be beyond the noise band by at least `k` ATR before
entering) may filter the false breakouts. This hypothesis tests it under the project's
standard turnover-lever discipline.

## Thesis and the null it must beat

**Proposed mechanism:** a shallow break (close barely beyond the band) is more likely a
false breakout that snaps back; requiring a deeper break at the decision bar selects
higher-follow-through entries. If real, this is ENTRY-QUALITY information.

**The prior that must be excluded (why this is likely a NO-GO):** every prior selectivity
lever on this book — Hurst (EXP-0026), VEI (EXP-0035/0036), gap/RVOL (EXP-0016/0024),
NQ↔ES confirmation (EXP-0018), percentile-momentum (EXP-0030) — raised per-trade quality
while cutting exposure and FAILED to lift risk-adjusted Sharpe, reading as a
turnover/capacity lever indistinguishable from randomly dropping trades and/or dying
against Null C. A depth gate is structurally the same object (a per-signal entry gate),
so the decisive controls are the matched-count random-drop null and Null C, not raw
Sharpe.

## Exact change

- Feature: `ext_atr` = signed break depth at the decision-bar close in ATR units, from
  `scripts/wfo.py::candidate_signals` (causal, known at the signal bar; baseline signals
  already have `ext_atr > 0`).
- Gate: keep decision-bar signals with `ext_atr >= k`, applied through the audited
  `entry_gate` path (`core/engine2.py` / `engine2_nb.py`); `k=0` reproduces the baseline
  bit-exact (all baseline signals kept). NO core engine change.
- Frozen baseline: `run(..., fill_mode="next_open", require_vwap=True,
  exit_check="every_bar", stop_ref="both")`, bands lb90, 30-min clock, NQ (primary) + ES
  (transfer).

## Primary metric

Zero-trade-day daily net-ATR-R Sharpe uplift (dSharpe) of the depth-gated book over the
frozen baseline, on the **NQ TEST era** (primary), with ES TEST transfer. Same metric,
split (TRAIN = first 60% of common sessions, TEST = last 40%), and cost model as
HYP-0035. All history is consumed research data, so TEST is a temporal validation split,
not a sealed holdout; the null battery carries the confirmatory weight (rule 26).

## Selection (TRAIN only, no TEST leakage)

- Sweep `k` over a fixed grid {0.00, 0.05, 0.10, 0.15, 0.20, 0.30, 0.50} ATR on NQ TRAIN.
- Select `k* = argmax` TRAIN dSharpe **subject to a deployable exposure floor
  retain >= 0.50** (keep >= 50% of baseline trades). The floor is the load-bearing
  discipline: it forbids picking a degenerate tiny-exposure high-per-trade cell, which is
  exactly the turnover-lever failure mode. If NO cell with retain>=0.50 has dSharpe>0 on
  TRAIN, declare **NO-GO on TRAIN** (the gate does not even help in-sample at deployable
  exposure) and stop.
- Freeze `k*` before touching TEST.

## Kill test (NQ TEST — ALL must hold, else REJECT)

1. **Real gate:** dSharpe >= +0.10 AND netR does not fall.
2. **Beats matched-count random-drop null** (decisive): randomly drop baseline signals to
   the gate's kept count, 200 draws; require frac(random dSharpe >= real) < 0.05. This is
   THE discriminator between real entry-quality selection and a rarity/turnover lever.
3. **ES TEST transfers with the same sign** (dSharpe > 0 and the random-drop null also
   favours real on ES).

## Confirmatory (only if 1–3 pass)

4. Drift-preserving **Null C** on NQ TEST bars (`_null_c_frame`, 40 draws), require
   frac(null >= real) < 0.05 and inspect the null center sign (positive center ⇒
   fewer-trades variance amplifier ⇒ reject; negative center ⇒ tied to the thing cut).
   Diffusivity gate must be preserved. Then require ES Null C same-sign.

## Kill conditions (any ⇒ NO-GO)

- No retain>=0.50 cell helps on TRAIN; or NQ TEST real gate fails; or the matched-count
  random-drop null is not beaten (frac >= 0.05); or netR falls; or ES sign does not
  transfer; or Null C center is positive / not beaten. A wash or negative result is a
  clean REJECT and a successful outcome (rule 25).
