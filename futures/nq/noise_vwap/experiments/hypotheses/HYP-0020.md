# HYP-0020 — A Laplace recency-weighted noise band beats the flat lb90 mean band

- Status: rejected by `EXP-0029`
- Created: 2026-07-22
- Origin idea: user proposal. The lb90 flat mean band beats shorter lookbacks
  (EXP-0025), but a flat mean under-weights recent sessions, so recent regime
  changes register slowly. Rather than TRUNCATE history (the EXP-0025 short-history
  failure), keep a long window but tilt the trailing per-slot average toward recent
  sessions with a Laplace kernel. Sweep the center-of-mass (peak/anchor horizon) and
  the decay rate, with slower decay paired to a longer lookback.
- Builder: Claude (Opus 4.8)
- Proposed mechanism: replace the flat trailing mean `sigma[d,mfo] = mean_k
  |move[d-k,mfo]|` (k=1..90) with a recency-weighted mean under a Laplace kernel
  `w_k = exp(-|k-mu|/b)`. `mu` = center-of-mass lag (peak weight session), `b` =
  decay scale (half-life `h`, `b=h/ln2`). If per-slot dispersion is non-stationary
  in a way the continuous stop does not already capture, up-weighting recent sessions
  should sharpen the band and per-trade selection.
- Exact change: swap ONLY the band construction —
  `core/session.py::noise_bands(bars, 90)` vs
  `core/bands.py::noise_bands_laplace(bars, mu, b, lookback, scale)`. The window is
  DERIVED, not an independent axis: `lookback = clip(ceil(mu + 5b), 90, 250)` so
  slower decay uses a longer lookback (the user's "slow decay for long lookback"),
  floored at 90 (never pure short history) and capped at 250 (coverage). `b -> inf,
  lookback=90` reduces to `noise_bands(bars, 90)` EXACTLY (uniform weights; proved in
  `tests/test_bands.py`), so the deployed baseline is the flat cell. Same engine, VWAP
  gate, 30-min RTH clock, every-bar (continuous) stop, next-open fills, costs.
- Grid: `mu ∈ {1, 5, 15, 30}` × half-life `h ∈ {5, 15, 40}` sessions (12 cells).
  `mu=1` = pure recency (the thesis); `mu>1` = "recent-ish but smooth over the
  noisiest latest session" (a bias/variance variant). `h` spans fast→slow decay;
  `h→∞` is the flat baseline.
- Two views (the EXP-0021 width-dial control):
  - RAW (scale 1.0) — exposes the width/capacity dial a tilt can introduce.
  - MATCHED — each cell rescaled so its MEDIAN band width equals the flat baseline —
    isolates the recency-tilt SHAPE. This is the real test.
- Frozen baseline: `core/session.py::noise_bands`, lookback 90 (continuous stop).
- Primary metric: zero-trade-day daily net-ATR-R Sharpe uplift of the best MATCHED
  cell over the flat lb90 baseline, on the common post-max-lookback (same-sample)
  date set, NQ primary + ES sibling.
- Kill test: Reject if the best MATCHED cell's Sharpe uplift is below +0.10 on NQ or
  net R falls below baseline. Because this is a 2-D (mu,h) search, the Null C uses the
  FAMILY-MAX statistic and runs ONLY if the gate passes (standing rule).
- Decisive diagnostic: residual `laplace_sigma / flat_sigma` by decision slot at
  matched width. Flat ≈1.0 everywhere ⇒ the recency tilt does not reshape the per-slot
  level ⇒ REJECT (the EXP-0021 quantile signature).
- Required controls: RAW vs MATCHED width; per-cell `wRatio`; net_pt/trade (the user's
  per-trade quality metric); trade count; derived-lookback coverage; ES sibling;
  causality + `b→∞` exact-reduction proved in `tests/test_bands.py`.
- Data scope: NQ primary + ES secondary clean Databento RTH through 2026; consumed
  data; common post-max-lookback date set (every cell defined on identical dates).

## Rationale and evidence

Distinct from EXP-0025 (surround/short-history), which TRUNCATED the window and found
short history strictly worse and the long lb90 the best bias/variance point. This
keeps a long window and only redistributes the trailing WEIGHTS toward recent
sessions — a recency tilt, not a truncation. It is also distinct from the
EXP-0020/0021/0022 recast programme, which reshaped the dispersion PROFILE (time
profile / distribution / up-down symmetry) at fixed flat weighting.

Prior expectation (adversarial): every (mu,b) cell is a linear reweighting of the same
per-slot `|move|` history. EXP-0021 found the matched-width residual ≈1.0 for a
quantile recast (the mean is a sufficient statistic at fixed width), and EXP-0025
found the continuous stop already supplies current-session vol adaptivity, so the band
only needs a stable long-run LEVEL. If per-slot sigma is roughly stationary the flat
mean is minimum-variance and no tilt beats it at matched width; a recency tilt would
then likely surface as a variance amplifier (null centers positive) rather than alpha.

## Result

Rejected by `EXP-0029` on both markets — the MATCHED-width gate fails on NQ and ES,
no Null C spent.

- NQ: every matched cell is WORSE than the flat baseline (Sh 1.26). Best matched
  mu5 h15 dSharpe −0.019; grid spans −0.019 → −0.219. Recency-tilting strictly degrades.
- ES: best matched mu1 h5 dSharpe +0.065 (below +0.10) is a width/capacity artifact —
  gross/trade FALLS (−0.081), 136 fewer trades — and does NOT transfer (the same cell is
  one of NQ's worst matched, −0.117).
- Decisive: residual `laplace/flat` by decision slot is FLAT — NQ ≈1.005, ES ≈1.08 —
  across all 13 slots. A Laplace recency tilt is just the flat band uniformly rescaled,
  with no slot-dependent reshape (the EXP-0021 quantile signature). The per-slot LEVEL is
  a sufficient statistic and the continuous stop already supplies recency vol-adaptivity;
  a tilt only adds estimator variance (NQ maxDD 4.7→8.2R at mu1 h5).
