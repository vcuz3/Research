# HYP-0037 — Smarter depth entry gate: side-asymmetric, always-fire, and band-relative depth

- Status: **REJECTED / NO-GO** (EXP-0049, 2026-08-16). Preregistered and run same day.
- Created: 2026-08-16

- Reviewer: unassigned

## Origin (SEARCHED — rule 26)

Three user-proposed refinements of the EXP-0048 confirmation-depth gate (a fixed
`ext_atr >= k` broke NO-GO: TRAIN-only Sharpe uplift, failed the matched-count
random-drop null on TEST). Each targets a specific weakness of the fixed-ATR gate.

## Arms

### Arm A — side-asymmetric depth (clock gate)
Separate thresholds for long vs short breakouts: keep a signal iff
`side==+1 and ext_atr>=k_long` OR `side==-1 and ext_atr>=k_short`.
Thesis: NQ up-drift makes long breakouts follow through on a shallower break, while
counter-drift short "panic" breaks need deeper confirmation → `k_long < k_short`.
Mechanism-consistent and points OPPOSITE to EXP-0022 (which *widened* the up-threshold
and hurt NQ by rejecting drift-driven up-breaks); here we *lower* the long threshold.

### Arm B — always-fire deeper threshold (threshold entry), era-resolved
First-crossing entry (`entry_mode="threshold"`, `entry_buf_atr=b`) rather than the
30-min clock gate, so a deep break is taken whenever it occurs instead of being dropped
when the decision bar is shallow — recovers the exposure the clock gate loses. Measured
against the DEPLOYED CLOCK baseline (not the over-firing `buf=0` threshold arm — the
EXP-0048 reconciliation error), broken out by era. CAVEAT: threshold mode has no
cooldown and over-fires (~4× trades), so Sharpe is exposure/churn-confounded; the clean
reads are per-trade net points and trade count vs the clock book. Descriptive
characterization, not a null-gated claim, unless a cell clears the clock Sharpe on TEST
at comparable exposure.

### Arm C — band-relative (per-slot) depth normalization (clock gate)
Gate on `ext_sigma = side*(close-band)/σ_slot >= k_σ` (break depth in band-halfwidth
units) instead of `ext_atr` (session-level ATR units). σ_slot is the per-slot noise
level the band is built from, so this is the scale-free unit (LEARNINGS #1): a fixed
`k·ATR` threshold is a TIME-OF-DAY SELECTOR because band/ATR drifts through the session
(super-diffusive morning, EXP-0020), whereas `k·σ_slot` matches the per-slot scale.
Diagnostic (run first): per-slot fire-rate CV of `ext_atr>=k` vs `ext_sigma>=k_σ` at
matched overall selection rate — expect the σ-gate CV to be lower if the ATR gate was
partly a clock. Whether correcting the confound changes the deployment verdict is the test.

## Exact change

All arms use the audited `entry_gate` (Arm A/C) or the audited `entry_mode="threshold"`
overlay (Arm B); `core/engine2.py` unchanged, all default-off. Feature `ext_sigma`
derived in-script from the audited `candidate_signals` `ext_atr` and per-slot `σ`
(`ext_sigma = ext_atr * ATR/σ`), no core change. Frozen baseline: deployed clock book
(`fill_mode="next_open"`, `require_vwap=True`, `exit_check="every_bar"`, `stop_ref="both"`,
lb90, 30-min clock). k=0 / band-only reproduces baseline bit-exact.

## Primary metric & split

Zero-day daily net-ATR-R Sharpe uplift on NQ TEST, ES TEST transfer. TRAIN first 60% /
TEST last 40% of common sessions (same as EXP-0035/0047/0048). Consumed research data;
null battery carries confirmatory weight (rule 26).

## Selection (TRAIN only)

- Arm A: 2-D grid k_long,k_short ∈ {0,0.05,0.10,0.15,0.20}; select argmax TRAIN dSharpe
  subject to retain>=0.50.
- Arm C: k_σ over a grid chosen to span the same selection-rate range as EXP-0048's k;
  select argmax TRAIN dSharpe subject to retain>=0.50.
- Arm B: no selection — report the buffer sweep TRAIN & TEST vs the clock baseline, per era.
- If no retain>=0.50 cell has TRAIN dSharpe>0 → NO-GO on TRAIN for that arm.

## Kill test (NQ TEST — ALL must hold per gated arm, else REJECT)

1. dSharpe >= +0.10 AND netR does not fall.
2. Beats the matched-count random-drop null (200 draws, frac(random>=real) < 0.05) — the
   decisive discriminator vs a rarity/turnover lever.
3. ES TEST transfers with the same sign.

## Confirmatory (only if 1–3 pass): Null C (40 draws), frac<0.05 + null-center sign + ES same-sign.

## Kill conditions (any ⇒ NO-GO for that arm)

No retain>=0.50 TRAIN cell helps; or NQ TEST real gate fails; or random-drop null not
beaten; or netR falls; or ES sign does not transfer; or Null C center positive / not
beaten. A wash/negative is a clean REJECT and a successful outcome (rule 25).

## Result (EXP-0049)

**NO-GO all three arms, both markets.** None clears the NQ TEST +0.10 gate, so no
arm reached the matched-count random-drop null or Null C (gate rule). Deployed
clock baselines: NQ TRAIN Sharpe 1.268 / TEST 1.322; ES TRAIN 0.481 / TEST 1.070.

- **Arm A (side-asymmetric):** TRAIN grids MILDLY support the user's asymmetry
  direction (short threshold wants to be deeper than long) — NQ argmax
  k_long=0.10/k_short=0.15 (TRAIN +0.217, retain 0.51), ES k_long=0.05/k_short=0.20
  (TRAIN +0.414, retain 0.55) — but neither transfers: NQ TEST dSharpe −0.011
  (netR −4.03), ES TEST −0.268 (netR −9.93). In-sample asymmetry, no out-of-era edge.
- **Arm B (always-fire deeper threshold):** LOSES to the deployed clock book at
  every buffer and every era on both markets (d_sharpe_vs_clock negative
  throughout). Deeper buffers raise per-trade net points only by shedding ~4× churn
  exposure. Only a cherry-picked NQ recent-20% slice (buf≈0.15, +0.295, n=775) wins;
  the same buffer is negative over full TEST and ES recent-20% is negative
  everywhere. The clock gate already captures the deep-break benefit without the churn.
- **Arm C (band-relative per-slot depth):** the diagnostic CONFIRMS the confound —
  a fixed ext_atr cut IS a mild time-of-day selector, and the band-relative cut is
  2–3× flatter per slot (NQ CV 0.088→0.036, ES 0.115→0.050). But correcting it does
  NOT change the verdict: TRAIN k_sigma*=0.20 fails TEST (NQ dSharpe −0.007 netR −3.57;
  ES −0.405 netR −12.24). The depth gate is a turnover lever whether measured in
  session-ATR or band units.

Confirmation-depth entry family now closed (EXP-0048 symmetric + EXP-0049
asymmetric/always-fire/band-relative). Evidence: `artifacts/runs/EXP-0049/`.
