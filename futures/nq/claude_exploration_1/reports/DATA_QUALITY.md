# Data quality (rule 9a)

Generated by `scripts/build_panel.py`. One row per equity-RTH minute
(09:30-16:00 ET) for every near-complete, non-degraded session on the ES
calendar. Prices are roll-adjusted log levels; the dollar index is the
published ICE geometric basket rebuilt from CME FX futures.

Read the staleness tables before any cross-asset claim: forward-filled
minutes manufacture autocorrelation and fake lead-lag, which are precisely
the effects this project measures.
