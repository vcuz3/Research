# HYP-0001 — Momentum works only when VEI is high (VEI as a momentum regime switch)

- Status: mechanism CONFIRMED, edge REJECTED (EXP-0004) — kill-test 1 failed both markets
- Created: 2026-07-26
- Origin idea: `experiments/IDEA_BACKLOG.md` item 1, promoting Study D (EXP-0003), which
  found trailing→forward 30-min return correlation ≈0 in low/calm VEI but +0.10 (NQ) /
  +0.096 (ES), CI excluding 0, when VEI>1.10.
- Builder: Claude (Opus 4.8)

## Proposed mechanism

VEI (intraday Wilder ATR(10)/ATR(50)) is not a direction predictor, but Study D shows
the tape TRENDS (positive short-horizon return autocorrelation) only when volatility is
expanding (VEI>1.10). So a causal momentum rule — go with the trailing 30-min move —
should have positive expectancy ONLY in the high-VEI regime, and ≈0 in calm/contraction.
If true, VEI is a strategy-TYPE switch even though it carries no directional information.

## Exact change (the strategy)

Purpose-built causal simulator (`core/strategy.py`), 30-min RTH decision clock:
- At decision bar m (close), if the gate holds, take side = sign(trailing 30-min
  return). Fill at the NEXT bar open (m+1), exit at the open 30 min later (one decision
  period; flat at session close). Non-overlapping single-position bets.
- Gate variants: `high` (VEI>T), `low` (VEI<=T), `all` (ignore VEI) — the dose-response.
- **Preregistered primary cell: `high`, T=1.10, horizon=30** (the Study-D regime cut,
  NOT a swept maximum). T swept over VEI quantiles only as SENSITIVITY.
- Costs: conservative per-interval round-trip (NQ 0.35 pt, ES 0.215 pt); gross reported.
- R = net points / causal daily ATR (prior-14-session mean RTH range).

## Frozen baseline

`all` (unconditional momentum) and `low` (anti-thesis) on the same clock/costs. The
dose-response prediction is high >> low, with `all` in between; `low` ≈0 or negative.

## Primary metric

Full-sample zero-trade-day daily net-ATR-R Sharpe of the preregistered `high` cell; net
R and day-t co-primary. Equal-weight per-bet, session-level daily aggregation
(non-overlapping bets ⇒ no concurrency, rule 12/13).

## Kill test (preregistered)

1. **Real gate:** `high(1.10)` net R>0 AND daily Sharpe>0 AND day-t>=2, AND beats
   `low(1.10)` on net R/Sharpe (correct-sign dose-response). Fail ⇒ REJECT (no nulls
   spent, standing rule).
2. **Rarity discriminator (always if gate passes):** matched-count random-decision-bar
   null — momentum at the SAME number of RANDOM decision bars (any VEI). If random
   equal-count matches real (frac(rand>=real)>=0.05), the VEI gate is a rarity/turnover
   filter ⇒ REJECT as alpha.
3. **Machinery discriminator (decisive):** path-preserving Null C (return shuffle,
   `core/nulls.py` = audited `noise_vwap` `null_c_returns`, diffusivity-gate validated).
   Recompute VEI + trailing return on the shuffled path, rerun `high`. Order (serial
   dependence) destroyed, drift preserved, so a real momentum edge must beat the null
   (real > null center, p<=0.05). Null reproduces P&L ⇒ machinery ⇒ REJECT.

Only a cell passing all three is a candidate edge (still discovery on consumed history,
holdout-pending — rule 26).

## Required controls

`all`/`low` dose-response; T sensitivity sweep; horizon check (15/30/60); ES
cross-market must reproduce the sign; gross vs net (rule 20).

## Data scope

NQ + ES clean Databento RTH 1-min 2011–2026, common post-warmup sample. Consumed
research history, not a sealed holdout.

## Multiple-testing note

Primary is the single preregistered cell (T=1.10, H=30); the sweep is labelled
sensitivity. Prior is strongly skeptical: noise_vwap momentum is volatility-INDEPENDENT
and every vol-selectivity screen there was a turnover lever, so a VEI momentum edge must
clear the rarity AND Null-C bars to count.

## Rationale and evidence

Study D (`reports/FINDINGS.md`, EXP-0003). This experiment (EXP-0004) is its
preregistered strategy test.

## Verdict (EXP-0004)

Mechanism CONFIRMED, edge REJECTED. Gross dose-response is clean and correct-signed on
both markets — momentum's positive gross expectancy lives in the high-VEI regime
(`high` gross +0.96 pt/t NQ / +0.38 ES; `low` ≈0/neg) — confirming Study D at the
strategy level and transferring to ES. But the preregistered `high>1.10, H=30` cell has
daily Sharpe +0.015 (NQ, t=0.06) / −0.073 (ES): the per-trade tilt is sub-cost and
daily-lumpy. KILL-TEST 1 fails → matched-count random null and Null C not spent
(standing rule). A real per-trade signal that does not monetize — the recurring project
pattern. Horizon H=60 is the only sensitivity lead (t≈1.4–1.7, still <2, post-hoc).
See `artifacts/runs/EXP-0004/review.md`.

### Erratum (EXP-0005, 2026-07-26) — verdict unchanged

The preregistered primary cell is untouched, so the REJECT stands. Two corrections to
the sensitivity reading:

1. **The H=60 cell violated this hypothesis's own declared estimand** (rule 13): a
   60-min hold on a 30-min clock runs up to two concurrent positions, not the
   "non-overlapping single-position bets" declared under *Exact change*. Corrected:
   NQ Sharpe +0.442 (t 1.70) / ES +0.526 (t 2.02) for a true 1-unit book; +0.288 /
   +0.249 on a proper 60-min clock. `simulate` now enforces non-overlap by default.
2. **The horizon lead is cost amortisation, not signal.** EXP-0005's term structure
   shows the momentum information peaks at 5–10 min and decays to ≈0 by 90–120 min on
   both markets, so a longer hold buys a better cost ratio rather than more edge.

The mechanism itself was independently audited and survived: HYP-0002 confirms Study D's
regime contrast is not a time-of-day artefact.
