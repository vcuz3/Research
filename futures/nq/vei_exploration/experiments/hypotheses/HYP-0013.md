## Rationale and evidence

The proposal is a good one on its face and it targets a real gap. EXP-0011's rejected
multi-horizon set was `[rv_60m, rv_120m, session_rv, prior_session_rv, prior_rv_5d,
prior_rv_20d]` — six measurements of the same quantity over different windows. That set
saturating at +0.009 is weak evidence that VOLATILITY LEVEL is saturated, and no evidence
at all that the forecast cannot be improved, because the set never contained a second
dimension. `jump_share_60m` (what FRACTION of recent variance came from jumps rather than
diffusion), `path_efficiency_15m` (did price TRAVEL or CHURN) and `overnight_rv_slot_z`
(what happened while the market was closed) are genuinely different questions.

Two reasons for caution, both stated before the run so neither can be invented afterwards:

1. Three of the four new variables are still ratios or shares of realised volatility over
   the same recent window that `range_rv_15m` measures. Low LINEAR correlation between a
   ratio and its own scale is expected and does not imply independent information — this
   project established exactly that in EXP-0008, where a ratio's apparent quality was
   entirely its numerator's level. Decorrelation is necessary for incremental value, not
   sufficient.
2. The seasonal swap is a substitution, not an addition. `fwd_abs_bp_slot_median90` is the
   same construction as the core's seasonal applied to endpoint displacement instead of
   path volatility. Since the target is path volatility, the swap most likely gives up
   information rather than adding it, and if `user6` underperforms `core` the attribution
   arms should show the swap as the cause rather than the four additions.

The most valuable outcome is not the pass/fail. It is KT3: whether any of these dimensions
touches the expansion-magnitude cell. If `overnight_rv_slot_z` or `jump_share_60m` lifts
that specific number, it is direct support for backlog item 13 (scheduled events as the
anticipatable source of expansion) and tells the next run where to look.

## Outcome

**KT1 CONFIRMED on both markets; KT2 FAILED on both; the proposed MECHANISM REFUTED.**
Disposition: **confirmed, not adopted** — the same ruling EXP-0011's multi-horizon set
received, and for the same reason. Settled by `EXP-0016`.

- **KT1 PASS.** Paired within-slot IC delta of `user6` over `core`: **+0.0090
  [+0.0082,+0.0099] NQ / +0.0099 [+0.0091,+0.0109] ES**, positive in 11/11 years and at
  11/11 slots on both markets. The set genuinely adds information.
- **KT2 FAIL** on both, against the +0.010 bar set in advance from EXP-0011's precedent.
- **KT3: the cell is lifted** (+0.0063→+0.0580 NQ, +0.0558→+0.0943 ES) — but see below,
  because the lift does not belong to this feature set either.
- **Mechanism refuted by a post-hoc control.** `core_levels3` — core plus `rv_15m`,
  `rv_60m`, `rv_120m`, three deliberately REDUNDANT measurements of the same quantity,
  precisely the redundancy the proposal was built to avoid — matches or beats the
  decorrelated six on every axis with fewer added features: delta **+0.0093/+0.0107**,
  lower log-MSE, lower MAE, and expansion-call skill **+0.100/+0.120** against `user6`'s
  +0.058/+0.094. The binding constraint was never redundancy; it was that the core had
  exactly ONE state variable.
- **Attribution.** Entirely the four additions (`core_plus4` +0.0090/+0.0098). The
  seasonal swap is a near no-op (`swap_only` +0.0005/+0.0006) because the two seasonals
  correlate +0.937/+0.910 — caution 2 in this file was directionally right about the swap
  being a substitution, though it proved inert rather than harmful. `new4_only` collapses
  to +0.4491/+0.5251: supplements, not standalone predictors.
- **The premise, measured.** Partly right: the four new variables ARE near-orthogonal to
  each other (`jump_share_60m` ~ `rv_ratio_15_60` +0.000, `overnight_rv_slot_z` ~
  `path_efficiency_15m` +0.009). Partly not: `overnight_rv_slot_z` ~ `range_rv_15m`
  +0.429/+0.460, and the two seasonals +0.937/+0.910. Caution 1 in this file is upheld —
  decorrelation is necessary for incremental value, not sufficient.
- **The result worth keeping is neither the pass nor the fail.** Three independent feature
  sets now buy the same +0.009..+0.011 on the LEVEL axis, so the level is SATURATED — a
  property of the target, not of any feature set — while the expansion-magnitude cell is
  not, moving from +0.006/+0.056 to +0.100/+0.120. EXP-0011 rejected multi-horizon on the
  one metric that cannot discriminate between feature sets. See
  `artifacts/runs/EXP-0016/review.md` and FINDINGS section P.
