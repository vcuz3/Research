## Proposed mechanism (long form)

Every feature this project has tested is a function of PAST PRICE: the two-input core,
EXP-0011's six multi-horizon variables, EXP-0016's decorrelated six and its redundant
level control. Finding P established that they all converge on the same within-slot
level-IC ceiling of +0.009..+0.011, i.e. the level axis is saturated as a property of
the target rather than of any feature set.

VIX is the first available input that is **not past price**. It is the option market's
forward-looking price of volatility, so it can contain volatility that has been
*scheduled* but has not yet happened — FOMC, CPI/NFP, opex, quarter-end. That is
precisely the information backlog item 13 argues is missing, and precisely the cell
EXP-0015 found the core cannot handle: expansion-call log-MSE skill over persistence is
only **+0.008 NQ / +0.061 ES**, against +0.300/+0.211 on contraction calls. The core
ranks expansions correctly but cannot size them, and scheduled events are the
anticipatable source of expansion.

## Exact change

Features only. Same target (`fwd_rv_bp`), same frozen learner
(`core.forward_vol.make_model`), same expanding-window annual walk-forward from 2016,
identical rows across all arms.

New causal inputs from `core/vix.py`, joined so that a VIX 15-minute bar is admissible
only if it closed at or before the decision's information cutoff (`ts_utc + 1m`), which
is asserted in code, with staleness recorded per row.

## What the exploratory pass ALREADY showed (screens, not results)

Declared here so the run's contribution is not overstated (rule 26). Before this
hypothesis was written, a descriptive pass on the joined panel established:

1. VIX's standalone within-slot IC against `fwd_rv_bp` is **+0.675 NQ / +0.670 ES** —
   strong, but BELOW `past_rv30_bp` (+0.846/+0.838) and `range_rv_15m` (+0.859/+0.854).
   As a volatility-LEVEL proxy VIX is worse than what the core already holds. It does
   beat the causal same-slot median (+0.393/+0.362), i.e. it is a better seasonal anchor
   than a 90-session trailing median, which is not what the core needs.
2. The naive variance risk premium `vrp_log = log(implied30 / realised30)` is
   **-0.856 / -0.844 correlated with `past_rv30_bp`**. Because VIX is a daily-scale
   quantity that barely moves across a 30-minute decision clock, the numerator is nearly
   constant within a session and the ratio is dominated by its DENOMINATOR. This is
   finding H in a new costume — a ratio that is really a rescaled version of one leg —
   and the degenerate control settles it the same way: the bare denominator
   (`past_rv30_bp`, |IC| 0.846) beats the ratio (|IC| 0.612) outright.
3. Consequently the raw VRP is a TIME-OF-DAY selector in exactly the sense of finding I:
   mean `vrp_log` runs -0.110 → +0.689 across the eleven NQ slots (implied/realised
   0.85 → 1.77; ES 1.23 → 2.13), because implied is flat by construction while realised
   decays through the session. Anything threshold-like must use the same-slot z-score.
4. Residualising the premium on realised volatility leaves the VIX LEVEL plus noise
   (algebraically, `log(imp) - log(real)` residualised on `log(real)` is `log(imp)`), so
   `vix_slot_z` IS the conditioned premium. There is no separate premium dimension.

None of the above speaks to the primary metric below, which is why it can still be
preregistered.

## Arms

All on one common sample, identical rows, identical learner, identical target.

| `core_pastrv` | core + `[past_rv30_bp]` | **degenerate control 1** |
| `core_levels3` | core + `[rv_15m, rv_60m, rv_120m]` | **degenerate control 2** (EXP-0016) |

`core_pastrv` is the control this hypothesis most needs. Since the premium is mostly its
denominator (screen 2), handing the model `past_rv30_bp` reproduces most of what the
premium could contribute WITHOUT any implied-volatility information. If `core_vix` does
not clearly beat `core_pastrv`, VIX has added nothing beyond making the persistence
benchmark visible to the learner. `core_levels3` carries EXP-0016's lesson forward: pair
every clever candidate with a deliberately redundant one.

## Primary metric

Per backlog item **20** ("choose the scoring metric BEFORE the next feature test", and
never score on a saturated axis), the deciding metric is the **expansion-call log-MSE
skill over persistence** — the one cell demonstrated to still move (core +0.008/+0.061
vs `core_levels3` +0.100/+0.120).

Reported both on each arm's own expansion set (EXP-0016's definition, so the numbers are
comparable to that run) and on the COMMON expansion set defined by `core`, so the arms
are also compared on identical rows.

Secondary, reported but explicitly NOT deciding: within-slot Spearman IC against
`fwd_rv_bp` and its paired delta over `core`. Finding P showed this axis is saturated
and therefore cannot discriminate between feature sets.

## Kill tests (declared before the run)

- **KT1 — statistical.** REJECT unless the paired within-slot IC delta of `core_vix`
  over `core` is positive with its 90% session-block CI excluding zero on BOTH markets.
  A necessary condition only; passing it proves nothing about the decision axis.
- **KT2 — the decision metric.** The bar is the REDUNDANT control, not the core:
  `core_vix` must beat `core_levels3`'s expansion-call skill over persistence
  (**+0.100 NQ / +0.120 ES**, published by EXP-0016) on BOTH markets. Beating only the
  bare core is not evidence, because three unrelated past-price feature sets already do
  that. Set from precedent before the run.
- **KT3 — mechanism.** VIX is an **SPX** measure: it is native implied volatility for ES
  and only a proxy for NQ (whose own index, VXN, is not in this workspace). The mechanism
  therefore predicts the gain is **ES ≥ NQ**. If VIX helps NQ materially more than ES,
  the mechanism is falsified and whatever is being measured is not this market's implied
  volatility. This is a genuine cross-market asymmetry prediction, not the usual
  "both markets agree" robustness check.
- **KT4 — degenerate control.** If `core_vix` does not beat `core_pastrv` on the primary
  metric, the result is attributed to the model gaining its own benchmark rather than to
  implied volatility, and the hypothesis is REJECTED regardless of KT1.

## Robustness arms (run regardless of outcome)

- **Timing.** Re-run the candidate with `lag_bars=1`, which drops back a further full
  15 minutes. The clocks align exactly (decision cutoffs at :00/:30 coincide with VIX bar
  closes), so this establishes that no result depends on the join boundary.
- **Era.** Per-year and per-slot deltas, since VIX's own regime is highly era-dependent.

## Data scope and coverage

- `futures/data/vix/CBOE_DLY_VIX, 15_*.csv`, ten contiguous non-overlapping tiles,
  2011-08-01..2026-07-17, 101,981 bars, zero duplicate timestamps.
- Join rate 98.6% of decision rows. The 1.4% loss is **87 US market holidays** on which
  CME futures trade a shortened session but cash VIX does not publish at all; 86 of the
  87 are partial futures sessions and 85 are wholly unjoined. The loss is therefore
  whole-session rather than slot-selective, and the holiday calendar is known in advance,
  so the exclusion is causal (rule 9a). Quote staleness is 0 minutes on 41,115 of 41,134
  joined rows.
- Consumed research history. This is NOT clean holdout evidence and cannot be
  confirmatory (rule 26). Only observations after 2026-07-14 remain clean.

## Limitations declared in advance

- Spot VIX only — no VIX9D/VIX3M, so no implied term structure, which is where much of
  the scheduled-event signal would normally sit.
- 15-minute resolution against a 30-minute decision clock.
- NQ and ES are correlated markets, so their agreement is a dependent robustness check,
  never two independent tests.
