# HYP-0004 — Attribute LSE versus Databento yearly performance differences under identical SMA200 rules

- Status: proposed
- Created: 2026-08-24
- Origin idea: none
- Builder: Codex
- Proposed mechanism: A matched common-calendar comparison separates strategy-specification differences from vendor return, SMA signal, volatility sizing, coverage, and endpoint effects.
- Exact change: Apply the EXP-0005 SMA200 gate and 10%/60-day/lag-one/3x/capped-cost rules to Databento EXP-0003 candidates, then compare both feeds on own and common calendars.
- Frozen baseline: EXP-0004 Databento unfiltered and EXP-0005 LSE SMA200
- Primary metric: Calendar-year compounded net return and Sharpe; common-date return correlation, gate disagreement, leverage difference, and attribution returns
- Kill test: If matching the strategy specification does not materially reduce the reported yearly gaps, do not attribute them to the SMA filter; report the remaining price, signal, sizing, coverage, and endpoint components explicitly.
- Required controls: Same SMA200 construction, strict 200-close warmup, lagged 60-leg volatility estimate, 10% target, 3x cap, identical cost function, zero-return inactive days, common-date subset.
- Data scope: Databento valid candidates 2011-08-02..2026-07-14 and LSE NQ.F 2016-05-29..2026-08-12; full history already consumed.
- Multiple-testing note: Diagnostic reconciliation only; no strategy selection or edge claim.

## Rationale and evidence

The previously reported tables used different gates and therefore cannot identify a data-vendor effect.
