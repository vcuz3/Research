## Proposed mechanism

**There is no new quantity here, and the hypothesis should be read in that
light.** With `U = max(dp,0)`, `D = max(-dp,0)`, `U-D = dp`, `U+D = |dp|`, and a
linear smoother `A_n`:

    RSI = 100·A_n(U)/(A_n(U)+A_n(D)) = 50 + 50·A_n(dp)/A_n(|dp|)

exactly — verified to 3e-14 in `tests/test_core.py`. RSI is a **smoothed trailing
return divided by a trailing absolute-return volatility**, rescaled to [0,100].

On the 30-minute decision grid the increments `dp` **are** `past_30`, the series
finding B already fades and which beat every session anchor (+0.197 pip t+3.92 on
6E / +0.384 t+5.96 on 6B). So RSI(14) is a differently-normalised sibling of the
project's own best signal. Two dimensions could in principle add something:

1. **Smoothing.** RSI's numerator is a 14-period Wilder average of the increments
   rather than one increment. That is a genuinely different (longer, smoother)
   momentum measure.
2. **The normaliser.** RSI divides by a *trailing-window* volatility. The project
   divides by a *causal same-slot* dispersion. These are not the same correction,
   and which is better is an open, transferable question.

**The competing account, and the reason this is worth running at all:** RSI's
denominator is a trailing window, so it **lags volatility transitions**. After a
quiet stretch gives way to a busy one, the denominator still reflects the quiet
period, so RSI reaches 70/30 more easily. A fixed 70/30 cut may therefore be
partly a **time-of-day selector** — precisely the LEARNINGS 2026-07-27 failure
mode, on a feature whose thresholds are an industry convention rather than a
calibration. The same-slot z-score exists in this project *because* that lesson
was learned; RSI is the natural test of whether the conventional alternative is
adequate.

**Stated in advance: this cannot produce a tradable result.** Finding B1 puts the
whole trailing-return family ~8x under the most optimistic cost floor, and a
re-normalisation cannot cross that gap. The deliverable is a measurement, and the
run is justified by the methodological question, not by a search for an edge.

## Exact change

- Feature: `rsi_14` on the decision grid, Wilder recursion **seeded with the
  textbook n-bar SMA**, not `ewm(adjust=False)` (LEARNINGS 2026-07-26 — the
  `min_periods` shortcut masks rather than seeds and this workspace has already
  paid for it once). Runs continuously across contiguous trade dates and resets
  only where the retained session sequence breaks, so the warm-up is paid ~once
  rather than 3,400 times.
- Bet: fade the extreme. Short when `rsi_14 >= 70`, long when `<= 30`; entry
  `open(m+1)`, exit `close(m+30)` (rules 1, 2, 15).
- Estimand: per-bet mean with a session cluster-robust SE. The session-averaged
  value is printed only as a contrast, with `corr(session mean, count)`.
- Comparators, all at the **same global selection rate** the 70/30 cut produces
  (LEARNINGS 2026-07-27 method note 4 — otherwise a selectivity dial is being
  read, not a signal):
  - `rsi_num_14` — the bare NUMERATOR, no denominator at all. The degenerate
    control that answers "is the ratio doing anything?"
  - `dev_past30_z` — the project incumbent, `past_30` over the causal same-slot
    scale.
  - `past_30` raw — no normalisation whatsoever.

## Kill test — written before the run

Let `M(s)` be the per-bet mean of fading signal `s`, all at the matched selection
rate, with a session block-bootstrap 95% CI.

**REJECTED if ANY of:**

1. **Sign/significance.** `M(rsi_14) <= 0`, or its CI spans zero, on either
   product.
2. **Degenerate numerator.** `M(rsi_14)` does not exceed `M(rsi_num_14)` on both
   products. If the bare numerator matches or wins, the denominator is decoration
   and RSI is a rescaled smoothed return (LEARNINGS 2026-07-27).
3. **Project incumbent.** `M(rsi_14)` does not exceed `M(dev_past30_z)` on both
   products. Standing caution #1: a new signal must clear the incumbent, not just
   clear zero.
4. **Incremental information.** `partial_spearman(rsi_14, fwd_30 | past_30)`
   collapses to under half its raw rank IC on both products.

**Reported but NOT part of the kill test** (they cannot save the hypothesis, only
explain it):

- Per-slot selection-rate CV of the fixed 70/30 cut versus the incumbent's at
  matched rate. A materially higher CV means the conventional threshold is partly
  a clock — a finding in its own right, and the one I expect.
- Neighbouring windows n=7 and n=28 (rule 18).
- 6J, since it is now wired; not part of the two-product kill test.

## Required controls

- **Matched selection rate on every comparison**, set by whatever rate 70/30
  produces. Unmatched comparisons are a selectivity dial.
- **Shared-decision-bar sizing** — this project's artifact is worth 68%/88% of the
  naive estimate, so the `close(m)` variant is reported to size it here too.
- **Session-averaged estimand contrast** with `corr(session mean, count)`.
- **Era stability** per year, and **era-appropriate costs** built from
  `tick_size(product, year)` — never a single tick figure across the sample.
- **Cross-product**: 6E and 6B must agree; they are correlated, so this is
  necessary and cheap, not sufficient.
- **Rule 9a**: report how many decisions `rsi_14` is undefined for, by block. A
  feature that resets and needs 14 periods will delete decisions, and if that
  deletion tracks time-of-day liquidity it is a hidden filter.

## Rationale and evidence

- `reports/FINDINGS.md` §B — `past30` beats every session anchor; the incumbent
  RSI must clear.
- LEARNINGS 2026-07-27 — never select a ratio on a metric its numerator maximises;

## Review after execution

- Reviewer: Claude (Opus 5) self-review, 2026-08-03
- Decision: **REJECTED** on 6E, 6B and 6J
- Basis (matched ~11% selection rate, common sample, per-bet in each product's
  reporting unit):
  - arm 1 sign/signif — FAIL 3/3 (`rsi_14` +0.1099 t+1.13 / −0.0526 / −0.0173, all
    CIs spanning zero);
  - arm 2 bare numerator — FAIL on 6E (+0.1099 vs +0.1148) and 6J (−0.0173 vs
    +0.1235); technical pass on 6B only because BOTH cells are negative
    (−0.0526 vs −0.1515), which is not a win and is recorded as a substantive
    failure;

    +0.0332 against RSI's +0.1099 / −0.0526 / −0.0173;
  - arm 4 incremental — PASS 3/3, partial IC retains 62.6% / 51.2% / 50.9%.
- Mechanism, as predicted in advance: the fixed 70/30 cut is a **time-of-day
  selector**. Per-slot selection-rate CV 0.3637 / 0.3331 / 0.2226 against the
  incumbent's 0.0639 / 0.0600 / 0.0632 — **3.5-5.7x worse** — firing 6.40% in
  `asia` versus 16.07% in `overlap` on 6E while the incumbent is flat near 11%.
  The extreme slots are `mfo` 479 (ET 01:59) and 989/1019 (ET 10:29/10:59). Per
  finding C the `overlap` is where fading LOSES, so the threshold concentrates
  bets in the worst block.
- The ratio is barely a ratio: corr(RSI, its numerator) +0.9732; corr(RSI, its
  denominator) +0.0144 (6E).
- New rule-9a result (finding J): for a RECURSIVE feature the gap damage is
  DISPLACED by the memory length. Under a reset policy Asia's 5.78% missing bars
