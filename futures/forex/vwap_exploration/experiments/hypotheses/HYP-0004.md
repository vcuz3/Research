# HYP-0004 — Finding C's liquidity-block shape survives a volatility-matched split

- Status: tested — **not rejected** (EXP-0004)
- Created: 2026-08-03
- Origin idea: IDEA-0004
- Builder: Claude (Opus 5)
- Proposed mechanism: finding C reads as transitory-inventory microstructure
  (reversion where liquidity is thin, continuation where information arrives).
  The competing explanation is that `block` is a proxy for the absolute
  volatility level, which varies several-fold across the FX day. See
  'Proposed mechanism'.
- Exact change: none to the feature or the target. The single variable is the
  ESTIMAND: the block contrast is recomputed WITHIN strata of a causal absolute
  realised-volatility measure, instead of pooled.
- Frozen baseline: EXP-0002's block table (`artifacts/runs/EXP-0002/entryinfo_*.txt`,
  finding C in `reports/FINDINGS.md`), reproduced inside this run as the
  unadjusted arm.
- Primary metric: volatility-stratified `asia` − `overlap` per-bet contrast in
  pips for the `vwap` anchor at H=30, session block-bootstrap 95% CI, on both
  products.
- Kill test: see "Kill test" below. Rejected if `C_adj <= 0` or
  `C_adj < 0.50 * C_raw` on either product; upgraded to confirmed only if the CI
  also excludes zero on at least one product AND the volatility ratio between the
  cells moved materially toward 1 on both.
- Required controls: mirror arm (volatility contrast within blocks); volatility
  ratio before/after; non-overlapping volatility window; 3/5/10 stratum
  resolutions; per-slot P&L-vs-volatility regression; `past30` dissociation arm;
  cross-product; rule-9a per-block coverage of the volatility measure.
- Data scope: 6E and 6B, CME trade dates 2010-06-07 .. 2023-12-29 (EXPLORE),
  30-minute wall-clock decision grid (ET :29/:59). 2024/2025/2026 sealed.
- Multiple-testing note: 24 declared cells, all reported, none selected on; the
  primary metric is one pre-declared cell per product.

## Proposed mechanism

Finding C is currently **provisional** and blocks any use of the liquidity-block
shape. The claim is that anchor displacement *reverts* in the thin blocks
(`asia` +0.288 pip, t +5.18 on 6E) and *continues* in the London/NY `overlap`
(−0.282 on 6E, −0.300 on 6B), while the no-anchor `past30` arm has the opposite
profile.

The split is matched on time of day only — trivially so, since the blocks *are*
time-of-day windows. LEARNINGS 2026-07-31c established that an exactly
slot-matched split can still inherit a volatility gradient, and collapsed a
comparable cross-asset contrast from **+0.0496 [+0.0069,+0.0853]** to **−0.0047
[−0.0274,+0.0272]** once the same split was taken within volatility quintiles —
without weakening the split itself (the label spread was unchanged; only the
volatility ratio between the cells moved, 1.46 → 1.11).

FX volatility has a large and highly deterministic intraday profile, so the
confound here is *a priori* stronger than in that lesson, not weaker. Two
accounts predict the same block table:

- **H_micro (the finding-C account).** Thin books mean a given displacement is
  more inventory and less information, so it reverts; the overlap carries genuine
  information, so displacement persists. The operative variable is the *block*.
- **H_vol (the confound).** Reversion is a decreasing function of the absolute
  volatility level, whatever the hour. `asia` is the low-volatility tail of the
  day and `overlap` the high-volatility tail, so the block table is a volatility
  table wearing a liquidity label. The operative variable is *volatility*.

The two are separated by conditioning: stratify on absolute realised volatility
and ask whether the block contrast survives *within* strata, and (the mirror arm)
whether the volatility contrast survives within blocks.

## Exact change

Single variable: the estimand's conditioning set. Feature, target, entry
convention, threshold and horizon are unchanged from EXP-0002.

- Feature: `dev_<anchor>_z` (and `dev_past30_z`), exactly as EXP-0002 built them.
- Target: `fwd_30 = close(m+30) − open(m+1)` (rules 1, 2). No stop, no target, no
  barrier (rule 15).
- Bet: fade, `|z| >= 1.0`, `pnl = −sign(z) · fwd_30`, per-bet mean with a session
  cluster-robust SE (never session-averaged — LEARNINGS 2026-08-01).
- **New**: `rv_60`, the causal mean absolute one-minute price change over the 60
  minutes ending at `close(m)`, in pips. Strictly prior to the entry price
  `open(m+1)`, so it shares no print with the target. Strata are quintiles of
  `rv_60` taken over ALL decisions of that product (a stratification of a
  descriptive contrast, not a tradable selection rule — nothing here is entered
  on the basis of a bin).
- Robustness measure: `rv_lag_60`, the same statistic over minutes
  `(m−90, m−30]`, which shares no minute with the 30-minute signal window.

Adjusted contrast (direct standardisation on common support):

    C_adj = Σ_q w_q · (mean_pnl[asia, q] − mean_pnl[overlap, q]),
    w_q ∝ n[asia,q]·n[overlap,q] / (n[asia,q]+n[overlap,q])

so a stratum in which either cell is empty or thin contributes no weight, and the
estimate never extrapolates outside common support.

## Frozen baseline

`core/frame.py::build_panel` + `core/vwap.py` unchanged from the EXP-0002 commit.
The unadjusted block table is recomputed inside this run and must reproduce
finding C's numbers to 4 decimals (rule 23) before the adjusted arm is read.

## Kill test — written before the run

Let `C_raw` be the unadjusted `asia − overlap` contrast (the EXP-0002 quantity),
`C_adj` the volatility-stratified one, and `R_raw`, `R_adj` the corresponding
mean-`rv_60` ratios between the two cells.

**Finding C is REJECTED as a liquidity effect (and marked invalidated in
`reports/FINDINGS.md`) if EITHER of:**

1. **Sign.** `C_adj <= 0` on either product.
2. **Magnitude.** `C_adj < 0.50 · C_raw` on either product.

**Finding C is UPGRADED from provisional to confirmed only if, in addition:**

3. **Significance.** The block-bootstrap 95% CI of `C_adj` excludes zero on at
   least one product.
4. **The control actually did its job** — the arm that distinguishes "confound
   removed" from "split merely weakened" (LEARNINGS 2026-07-31c):
   `|R_adj − 1| < 0.5·|R_raw − 1|` on both products, and the effective bet count
   `n_eff = Σ_q w_q` retains at least 50% of the harmonic-equivalent unadjusted
   count. If arm 4 fails, the strata have no common support, the test is
   uninformative, and finding C stays **provisional** with that recorded — it is
   neither confirmed nor invalidated by an inconclusive control.

Anything else (arms 1-2 pass, 3 fails) leaves finding C provisional but not
volatility-explained.

## Required controls

- **Mirror arm (mandatory, LEARNINGS 2026-07-31c).** The other label conditioned
  on this one: the volatility contrast `q5 − q1` computed *within* blocks and
  standardised across them. Reading: if block dies within volatility strata and
  volatility survives within blocks, the operative variable is volatility; if
  both die, neither label carries anything and finding C is noise; if block
  survives and volatility dies, H_micro is supported.
- **Volatility ratio before and after**, per arm 4 — without it a collapse is
  uninterpretable.
- **Non-overlapping volatility window** (`rv_lag_60`, minutes `(m−90, m−30]`):
  `rv_60` shares its window with the `past_30` signal, so the `past30` arm could
  be attenuated mechanically by conditioning on a quantity built from the same
  minutes. `rv_lag_60` shares no minute with it.
- **Stratum resolution**: repeat at 3 and 10 strata. A result that only appears
  at one bin count is a bin artifact.
- **Per-slot regression**: across the 46 decision slots, correlate mean per-bet
  P&L against mean `rv_60`. This is the block-free view of the same question and
  does not depend on the four-block partition at all.
- **`past30` arm**: finding C's second half is that `past30` has the *opposite*
  block profile. Declared as a SECONDARY arm, not part of the kill test: the
  dissociation survives only if, after stratification, `C_adj[vwap] > 0` while
  `C_adj[past30] <= 0`.
- **Cross-product**: 6E and 6B must agree. They are correlated, so agreement is
  necessary and cheap, not sufficient.
- **Rule-9a coverage**: report how many decisions `rv_60` and `rv_lag_60` are
  undefined for, **by block**, before any contrast is read. A volatility measure
  missing preferentially in the thin blocks would re-create the exact hidden
  filter finding G was written about.

## Multiple-testing note

2 anchors × 2 volatility measures × 3 stratum resolutions × 2 products = 24
declared cells, all reported, none selected on. The primary metric is ONE
pre-declared cell (`vwap`, `rv_60`, 5 strata) per product; the rest is a declared
robustness surface read as a shape, not an argmax. No null is spent: per the
project's own gate a null is bought only once a real pass clears its primary
metric, and this run can only *remove* a claim, never create one.

## Rationale and evidence

- LEARNINGS 2026-07-31c — the volatility-matched split, and the requirement to
  report the cells' volatility ratio before and after so a collapse can be
  attributed.
- LEARNINGS 2026-07-27 — a fixed threshold on a session-reset feature is a
  time-of-day selector; the same-slot z-score used here is that fix, but it
  normalises the *dispersion of the anchor distance*, not the absolute volatility
  level, so it does not by itself remove the confound this run tests.
- `reports/FINDINGS.md` §C and `MEMORY.md` "Provisional hypotheses", both of
  which already name this run as the blocking control.

## Review before registration

- Reviewer: Claude (Opus 5), builder self-review
- Decision: registered
- Objections: the strata are full-sample quantiles, which is a two-sided
  statistic. Accepted here because the estimand is a descriptive contrast and no
  decision is taken on a bin (rule 8 governs what was *tradable*, and nothing is
  traded on a stratum). Recorded as a limitation rather than repaired, since a
  causal expanding quantile would change bin membership over the sample and make
  the strata themselves era-dependent.

## Review after execution

- Decision: **NOT REJECTED**

  ([+0.2302, +0.8952]) and FAIL on 6B ([−0.4120, +0.8096]); arm 4 PASS on both
