# HYP-0002 — A VWAP-anchor × band-multiplier × lookback grid contains a config that beats the baseline out-of-sample

## Mechanism / rationale

The frozen GC baseline (RTH VWAP, k=1.0, lookback=90) is weak (net Sharpe 0.46
per-trade, 0.07 sized). Three design knobs might recover a stronger, cost-surviving
timing edge:

1. **VWAP anchor** — the entry gate (`close vs vwap`) and the stop (`max/min(band,
   vwap)`) both key off VWAP. A Globex/ETH-anchored VWAP (reset 18:00 ET,
   overnight-inclusive) is a slower, higher-timeframe reference than the RTH-reset
   VWAP; it may filter/steer entries better.
2. **Band vol multiplier k** — `band = ref*(1 ± k*sigma)`. Wider bands (higher k)
   demand a larger displacement before entry (fewer, higher-conviction breakouts);
   narrower bands trade more.
3. **Noise lookback** — how many prior sessions define the same-time-of-day sigma.

## Exact change

Grid = anchor {rth, eth} × k {0.5, 1.0, 1.25, 1.5, 2.0} × lookback {5, 14, 30, 60,
90} = 50 cells. Everything else is baseline: 30-min Concretum decision clock,
require_vwap gate ON, stop_ref=both, exit_check=**decision**, next-open fills. The
VWAP anchor is a single-variable swap of the `vwap` column only (RTH window, RTH
bands, RTH clock all held fixed) — it does NOT re-open the session-hours question
(HYP-0001, already rejected). Run through the audited numba engine
(`core.engine2_nb`, bit-exact vs `core.engine`).

## Primary metric

Era-neutral annualized daily Sharpe on per-trade NET RETURN (net_pts / entry_px),
summed per session over a common date set (all cells share the lb=90 warmup). Gold
ran ~1200→3300 over the sample, so raw points inflate the recent era; normalize.
Tradable units (net pt/trade, day$net) reported alongside (rule 19/21).

## Kill test (declared before the run)

REJECT if **either**:
1. No grid cell beats the frozen baseline **out-of-sample** — i.e. the expanding-
   window WFO stream does not beat the static baseline, AND the best-in-sample cell
   does not beat the baseline on the (consumed) final-slice holdout; **OR**
2. The real best-of-50 in-sample Sharpe falls **within** the max-statistic Null-C
   distribution (best-of-50 on return-shuffled tape) at p > ~0.05 — i.e. the "best
   cell" is a multiple-testing artifact.

## Controls

- Max-statistic Null-C over the *whole* 50-cell search (rule 17/26): reproduce the
  full grid on each return-shuffled draw and compare the real best-of-50 to the null
  best-of-50 distribution.
- Static baseline (rth, k1.0, lb90) as the WFO and holdout benchmark.
- Diffusivity gate on every null draw (must equal the real 0.1000 pt = 1 gold tick).

## Data scope

GC RTH 2011-08-01..2026-07-16, 3557 common sessions (post lb=90 warmup). All
history is CONSUMED research data — the holdout is a robustness split, not sealed.
