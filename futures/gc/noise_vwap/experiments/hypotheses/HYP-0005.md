# HYP-0005 — Cross-asset conditioning: condition GC direction on contemporaneous ES noise-VWAP state

- Status: REJECTED (EXP-0007, 2026-07-19) — conditioning on the contemporaneous ES
  noise-VWAP state DESTROYS the GC edge (best net-Sharpe uplift −0.466 << +0.05 gate);
  `agree` halves gross and `es_dir` is net-negative. Direction-conditioning thesis
  disproven; re-pairing null not spent (real pass fails primary metric). See
  `artifacts/runs/EXP-0007/review.md`.
- Created: 2026-07-19
- Origin idea: IDEA_BACKLOG "Cross-asset conditioning (speculative; needs re-pairing null)"
- Builder: claude
- Proposed mechanism: EXP-0002 established that the GC noise-VWAP timing edge lives
  ONLY in the equity cash session (09:30–16:00 ET) and dies — indeed inverts and
  fails its own Null-C — in gold's native COMEX pit hours (08:20–13:30 ET). That is
  the signature of a cross-asset / shared-risk-factor phenomenon: the "gold edge"
  looks like equity-session intraday momentum bleeding into gold rather than a
  property of gold's own tape. If so, the contemporaneous ES (S&P 500) noise-VWAP
  STATE should carry information about the correct GC trade direction. Concretely,
  when ES is itself in a long breakout (ES close above its own noise-band AND above
  its own VWAP), a GC long breakout should be more likely to continue, and a GC
  breakout that DISAGREES with ES should be lower quality (a gold-specific move with
  no equity-session tailwind).
- Exact change: single conditioning overlay on the FROZEN decision-clock baseline
  (EXP-0005 relaxed bands; `core.engine` defaults, lookback=90, VWAP gate on, 30-min
  Concretum clock, next-open fills). At each GC decision bar we compute the ES
  noise-VWAP state `es_state ∈ {+1,-1,0}` at the SAME tod on the SAME date, using
  ES's OWN bars, ES's OWN cumulative RTH VWAP, and ES's OWN 90-session noise bands
  (identical construction to GC; ES is loaded through the audited `core.data.load_rth`
  / `noise_bands`, so ES's state is built by the same audited code). `es_state=+1` iff
  ES close>ES_upper AND close>ES_vwap; `-1` iff close<ES_lower AND close<ES_vwap;
  else 0. The GC engine's `want` (its own breakout direction) is then modified by one
  of three pre-specified `cond_mode` overlays (ONE variable, entries/exits/flips/fills
  otherwise identical to baseline):
    * `agree`  — take GC's own signal only when ES agrees: if `want != es_state`, set
                 `want = 0` (primary; the most direct "condition GC direction on ES").
    * `gate`   — take GC's own signal only when ES is in ANY breakout: if
                 `es_state == 0`, set `want = 0`.
    * `es_dir` — enter GC in ES's direction when GC is flat: `want = es_state`
                 (strongest form of "equity momentum drives gold"; secondary).
  Both baseline and every variant run on the COMMON GC∩ES date set so the only
  variable is the ES overlay, never the calendar. `cond_mode=None` is a strict no-op
  and is asserted BIT-EXACT against the frozen baseline (2692 trades / 974.60 pt).
- Frozen baseline: `reports/BASELINE.md` / EXP-0005 (relaxed bands, decision-clock
  stop): gross +0.362 pt/trade, net +0.217 @0.50 tick, day$net +31.0, net t=+1.30,
  net Sharpe 0.48; 2692 trades. Re-measured here on the GC∩ES common date set (the
  comparison baseline).
- Primary metric: per-day-clustered **net daily Sharpe** at 0.50 tick/side on the
  common date set, best conditioning variant vs the common-set baseline. Report gross
  (rule 20), trades/day, and long/short split — the `agree`/`gate` filters mechanically
  DROP trades, so a Sharpe rise on far fewer trades is exactly the rarity-filter failure
  mode the null must rule out.
- Kill test (declared before the run): REJECT if no conditioning variant raises net
  daily Sharpe over the common-set baseline by ≥ +0.05 @0.50 tick. If a variant DOES
  clear +0.05, it is REJECTED anyway unless the real conditioned Sharpe-uplift beats
  the **re-pairing null** (below): a variant whose uplift is reproduced by pairing GC
  with UNRELATED ES days is a rarity filter, not cross-asset information. A lower or
  equal Sharpe is a clean NO-GO; do NOT sweep cond_mode / thresholds to rescue it
  (Rule 26 — consumed history, high overfitting risk).
- Required controls:
  1. **Re-pairing null (Rule 18, HARD REQUIREMENT).** Pair each GC session with a
     RANDOM OTHER ES date's state series (aligned by tod), destroying the
     contemporaneous cross-information while preserving each leg's own dynamics (GC
     path unchanged; ES state marginal distribution unchanged). Donors are stratified
     by calendar YEAR so the null does not smuggle in an era mismatch. Repeated draws
     (≥200), compare the real conditioned Sharpe-uplift against the null-uplift
     distribution (z, and % of draws beating real). Gated on the real pass first
     clearing +0.05 (memory: gate-nullc-on-success-metric).
  2. Gross-vs-net decomposition + trades/day: is any Sharpe rise real quality or just
     variance reduction from dropping trades (rarity filter)?
  3. es_state marginal diagnostics: fraction of decision bars with ES long/short/flat,
     and the agree-rate — a near-degenerate es_state (almost always flat) would make
     `agree`/`gate` a near-total trade suppressor, not a signal.
- Data scope: GC RTH 2011-08-01..2026-07-16 (`data/GC_1m_clean.parquet`) ∩ ES RTH
  (`futures/nq/data/ES_1m_clean.parquet`, Databento clean, same UTC→ET convention),
  common date set, relaxed bands (BAND_MIN_FRAC=0.9). Consumed history — only a future
  shadow is a clean holdout.
- Multiple-testing note: three pre-specified cond_mode overlays (not a swept grid);
  the primary is `agree`, the other two are reported for completeness. If the best of
  three clears the gate, the re-pairing null is run on THAT variant and interpreted as
  the max over three (a mild, disclosed selection). No threshold/lookback search.

## Rationale and evidence

EXP-0002 (`artifacts/runs/EXP-0002/`, memory `gc-noise-vwap-replication`): COMEX pit
hours net Sharpe 0.21 vs equity 0.46 AND fail their own Null-C (z+0.04, 96% capture),
while the equity window's timing trace is the only one that beats noise (z+2.66). That
localisation to the equity cash session is the entire motivation: if gold's edge is an
equity-session artifact, ES's contemporaneous state should condition it. This is the
one un-consumed direction in the backlog that engages the MECHANISM rather than
curve-fitting GC's own parameters (band-k/lookback/anchor were consumed and rejected in
HYP-0002/EXP-0003). Prior expectation is guarded and the overfitting risk is high, so
the re-pairing null is a hard gate, not an optional add-on: a cross-asset conditioning
result is meaningless without a null that destroys exactly the contemporaneous
cross-information the thesis claims to use.
