# HYP-0001 — Clarified ATR-stop anchored Z-band has net FX mean-reversion value

- Status: proposed
- Created: 2026-08-07
- Origin idea: none
- Builder: Codex
- Proposed mechanism: Extreme 2.5Z deviations from a causal session TWAP or trailing SMA partially mean-revert after closing back inside the band.
- Exact change: Freeze 2.5Z arming, ATR(14) stop at 2.0x, 10-bar timeout, 1R target; select only session TWAP versus SMA 10/20/40/80 on pre-2020 data.
- Frozen baseline: User-confirmed Pine strategy, ported to next-15m-open entry and one-minute bracket replay.
- Primary metric: Fixed-quantity portfolio daily net-pip Sharpe at 1.0 pip round-trip cost.
- Kill test: Fail if 2021-2023 net mean pips <=0, daily net-pip Sharpe <=0, or fewer than 3/4 pairs are positive; require the same checks in 2024-latest for a provisional survivor.
- Required controls: Gross versus net, 0-2 pip cost stress, pair/year breakdown, one-minute adverse dual-touch resolution, unused 2020 embargo.
- Data scope: AUDUSD EURUSD GBPUSD NZDUSD clean 1m midpoint OHLC; train before 2020, 2020 embargo, OOS 2021-2023, holdout 2024-latest.
- Multiple-testing note: Five baseline candidates; selection only pre-2020; later windows never tune parameters.

## Rationale and evidence

The small baseline search answers TWAP versus SMA without tuning away the user-confirmed threshold or stop.
