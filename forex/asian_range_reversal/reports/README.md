# Reports

Maintain these current authorities:

- `BASELINE_REPLICATION.md`: claim-by-claim faithful result and discrepancies.
- `ENGINE_AUDIT.md`: execution/accounting tests, exceptions, and parity status.
- `FINDINGS.md`: reviewed experiment findings, including negative evidence.
- `FINAL_REVIEW.md`: critical pipeline review and proceed/watch/abandon decision.

Reports summarize evidence. Exact configs, logs, metrics, trades, and figures
remain in immutable run artifacts and are referenced by experiment ID.
