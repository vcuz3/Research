# RSI/z fade — DIRECTED follower-reverts-to-anchor cointegration test (FROZEN SPEC)

Preregistered 2026-08-06, before the run. Screen on consumed history (2012–2023);
2024+ sealed and NOT opened. This is a NEW hypothesis generated by the block-structured
result in `RSI_COINTEGRATION_GATE_REPORT.md` (rule 26: it cannot be credited from that run
and gets its own preregistration + null).

## Hypothesis

In a cointegrated FX block, the two legs are not symmetric: one leg (the FOLLOWER / error-
correcting leg) does most of the adjustment back to the cross-rate equilibrium; the other
(the ANCHOR / weakly-exogenous leg) does not. The cross-pair divergence fade (`diverge_hi`)
carries reversion information **on the follower leg, not the anchor leg**. The symmetric run
passed the null on EURUSD and NZDUSD and failed on GBPUSD and AUDUSD — a one-leg-per-block
pattern this hypothesis explains.

## Follower assignment — a-priori, from cointegration dynamics, NOT from the fade P&L

The follower must be assigned by a rule fixed before seeing which legs it selects, so it is
not a post-hoc pick of the two winners. Two independent a-priori rules are reported:

1. **Error-correction loading (primary).** On the EARLY era only, for each block (A,B) form
   the cross `c = logA − logB` and its causal deviation from a 120-bar trailing mean `dev`.
   Regress each leg's forward-30-min log change on `dev`: `beta_A`, `beta_B`. The
   error-correcting leg has the larger `|beta|` (it moves more to close the gap; sign is
   negative for the rich leg). **Follower = argmax(|beta|).** Uses price levels only, never
   the fade stop-engine P&L. (Limitation: shares some information with the fade's reversion;
   this is why the exogenous rule 2 is also reported.)
2. **Liquidity (exogenous cross-check).** Anchor = the more liquid leg (EURUSD > GBPUSD;
   AUDUSD > NZDUSD), so liquidity-followers = GBP, NZD. If rules 1 and 2 disagree, that
   disagreement is reported as the finding; neither is chosen to match the winners.

The assignment (both rules, and the beta table) is printed so the reader sees it was made by
rule, not by the answer.

## Directed test

Run `diverge_hi` at keeps {10, 20} on each of the four legs (delay 1, engine identical to
the confirmed regime matrix: event clock, non-overlap, 2R stop, 1-pip slippage, 30-min
horizon), scored as excess over the `|z|` frontier. Selection-corrected null: within-
(session-minute, era, SIDE) donor re-pairing of `z_partner` (the fix from
`RSI_COINTEGRATION_GATE_REPORT.md`'s method note — a side-folded feature must be permuted
within side, and the firing-rate invariant is asserted), real MAX over {keep 10, 20} vs the
null MAX. Because direction+form are now pre-specified, the only searched dimension is keep.

## Primary metric and kill test

- The directed hypothesis PASSES iff the two BETA-followers (rule 1) BOTH clear the null
  (`frac(null MAX >= real) <= 0.05`).
- Corroboration check (not a pass condition): do the beta-followers match the symmetric
  passers (EURUSD, NZDUSD)? Report yes/no.
- If a beta-follower fails the null, or the anchor leg of a block passes it, the directed
  structure is not supported → report honestly (rule 25/26). No leg is re-labelled to fit.

## Guardrails

- mean R beside mean pips and risk unit per leg.
- Report both a-priori follower rules; do not silently adopt whichever matches the winners.
- Correlated pairs ≈ 2 effective blocks; this test deliberately reduces the four diluted
  legs to two directed ones, which is the point.
- Economics unchanged expectation: even a clean pass leaves gross ~0.24 pip vs the ~0.70 pip
  commission floor; this is a mechanism/attribution test, not a deployment claim.
