- Status: preregistered (written before the material run, RULES.md rule 24)
- Created: 2026-08-01
- Origin idea: user request — replicate `futures/nq/noise_vwap` on EURUSD,
  GBPUSD, AUDUSD, NZDUSD, and adapt the exit because FX has no volume and
  therefore no VWAP.
- Builder: Claude (Opus 5)
- Frozen baseline: first port; the NQ/ES faithful result is the external
  reference (`futures/nq/noise_vwap/MEMORY.md`: NQ zero-day daily Sharpe ~0.92,
  vol-targeted ~1.18; ES weaker; RTY negative gross).
- Multiple-testing note: the session definition and the stop reference have no

  argmax. Any survivor is a searched survivor on consumed history (rule 26).

## Proposed mechanism

The published strategy claims intraday **momentum**: displacement beyond a
same-time-of-day "noise area" measured from the session open is followed by
continuation, and a session-anchored average price (VWAP) both confirms the
direction and supplies a trailing exit.

If that is a property of *intraday order flow around a session anchor*, it
should port to any instrument with a well-defined trading day. If it is instead
a property of the **equity index tape specifically** — a positive intraday drift
the breakout rides, which is this workspace's established reason NQ works and
RTY does not — it should NOT port to spot FX, which has no comparable intraday
drift. FX is therefore a test of the mechanism, not merely another instrument.

## Exact change

One structural substitution, everything else held from the NQ/ES reference.
There is no volume (`volume == -1` on 100% of 22.0M source rows), so the session
VWAP is replaced by the session **TWAP** — the cumulative mean of typical price,
which is exactly the VWAP formula evaluated with constant weights
(`tests/test_core.py::test_twap_is_vwap_under_constant_volume`).

The user's specific question is the stop. Three references are run:

| `stop_ref` | long stop below | uses the anchor? |
| --- | --- | --- |
| `both` | `max(upper, twap)` | yes — the published rule, TWAP-substituted |
| `band` | `upper` | **no** — fully volume-free |
| `anchor` | `twap` | yes — the paper's flagship VWAP-touch exit |

## Primary metric

Zero-day daily Sharpe of per-session net P&L in pips at **0.5 pip/side**, with
no-trade sessions entering as 0. Always reported alongside: gross pips/trade,
net pips/trade, total net R (R = net pips / causal prior-session ATR(14) pips),
the per-session t-statistic, and max drawdown.

## Kill test

REJECTED if **either** holds on the primary configuration:

1. **Gross gate** — median gross pips/trade across the four pairs is <= 0 before
   any cost. A negative gross is the RTY signature: a clean NO-GO that no exit,
   cost or sizing change rescues, and no null is spent on it
   (`ai_shared_memory/LEARNINGS.md`, 2026-07-19).
2. **Net gate** — fewer than 3 of 4 pairs reach net zero-day Sharpe >= +0.30 at
   0.5 pip/side. Four correlated-but-distinct majors are the transfer test; a
   result carried by one pair is not a port.

DOWNGRADED to "real but not deployable" if both gates pass but the
drift-preserving Null C fails on the majority of pairs.

Per the standing gate-Null-C rule, Null C is spent only if the real pass first
clears the primary metric.

## Required controls

- **always-long and always-short drift controls** (enter at the first decision
  bar, hold to session close). If these are ~0 on FX while the NQ version is
  strongly positive, the "no drift to ride" mechanism is confirmed.
- **entry-gate ablation** — separates the anchor's filter role from its stop role.
- **degenerate stop control** — `band` uses no anchor at all, so `both` minus
  `band` is what the volume-free substitution costs.
- **cost sensitivity** {0.25, 0.5, 1.0} pip/side, with gross reported
  separately throughout (rule 20).
- **Null C** (`core/nulls.py`, path-preserving return shuffle, opening atom
  pinned, invariants tested) — gated on the real pass clearing the primary.

## Declared search

- session: `fxday` (17:15 ET -> 16:59 ET) and `active` (03:00 ET -> 16:59 ET,
  London open -> NY close, which unlike `fxday` has a real overnight gap);
- `stop_ref`: `both`, `band`, `anchor`;
- secondary, reported but not selected on: entry gate on/off, stop-check cadence
  (`decision` vs `every_bar`), cost {0.25, 0.5, 1.0} pip/side.

## Data scope

2011-07-20 -> 2026-07-17 (NZDUSD from 2011-12-07), ~3,780-3,890 sessions per
pair per session definition. Consumed research history; only future observations
can be clean holdout evidence (rule 26). Coverage, the IBKR chunk-boundary gaps
and session-anchor stability are audited in `reports/DATA_QUALITY.md`.

## Rationale and evidence

The workspace has already established that this family's transfer is governed by
the target's intraday drift, not by the band machinery: NQ (strong drift) works,
ES is weaker, GC/YM are cost-fragile, and RTY has no gross edge at all because
its tape had no positive intraday drift. Spot FX has no structural intraday
drift in either direction, so the preregistered expectation is that the gross
gate is the binding one.
