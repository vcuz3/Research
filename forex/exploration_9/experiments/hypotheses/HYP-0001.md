# HYP-0001 — Run-length reversion is a grind-vs-lunge concentration effect, not magnitude

- Status: accepted (exploratory; not yet holdout-validated)
- Created: 2026-08-17
- Origin idea: user request — short-term reversion signal in EURUSD/GBPUSD, Frankfurt/London open → NY 12:00 window, to feed another strategy (fast-alpha style), NOT a standalone cost-viable edge.
- Builder: Claude (Opus 4.8)
- Proposed mechanism: After a short sequence of same-direction 5m candles, price mean-reverts over the next ~10–15 min. The predictive content is **persistence / how the move was accumulated**, not the size of the move. A move spread evenly across many bars (a "grind") reverts; the same displacement delivered in one sharp bar (a "lunge", k=1, max-bar share = 1) continues. Consistent with the workspace "sharp = continuation, grind = reversion" theme (NQ 5m continuation tape).
- Exact change: For each in-window 5m bar, compute the current same-sign run length k (sign = sign(close−open) ≈ sign of 5m return, since open==prev_close ≈ 0.9965). Features: run displacement (signed), causal-vol-normalised displacement `dsig = |disp| / trailing_vol`, integer count `k`, per-bar move `dsig/k`, and **max-bar share** `max|bar| / |disp| ∈ [1/k, 1]`. Target: folded reversion `−sign · forward_log_return` at 15 min.
- Frozen baseline: none (discovery study on the raw price series; no strategy engine yet).
- Primary metric: cluster-robust (by NY session day) t-stat on the folded 15m reversion and on the horse-race coefficients; signflip null p-value.
- Kill test: (a) reversion mean-fold not distinguishable from the signflip null (real ≤ null p > 0.05) ⇒ KILL; (b) displacement subsumes count/max-share in the causal joint regression ⇒ the "persistence, not magnitude" claim is KILLED and it reduces to ordinary magnitude reversion.
- Required controls: paired shared-close embargo (1-min grain), causal vol normalisation (no full-sample scaling in the predictor), signflip null (real |returns|, iid signs) through the full pipeline, session-day clustering.
- Data scope: EURUSD, GBPUSD 1m clean archives 2011-07-19 → 2026-07-17, resampled to 5m. Window: 08:00 Europe/Berlin (Frankfurt open) → 12:00 America/New_York (DST-correct, from each bar's own local time), weekdays. ~457k / ~460k in-window events per pair. **All history inspected — no clean holdout remains; only future data is a fresh holdout.**
- Multiple-testing note: horizons (1–60m), run lengths (1–6), two pairs, and several conditioners were swept during discovery. The count-vs-magnitude horse race and the signflip null were pre-specified as the confirmatory tests before the causal re-run; treat absolute t's as discovery-inflated and rely on the null and the sign/monotonicity.

## Rationale and evidence

See `reports/FINDINGS.md`. Summary:

- Reversion is real and null-validated: mean folded 15m reversion +0.097 pip (EUR) / +0.103 pip (GBP), sitting ~10σ above the signflip null (p = 0.005, the 1/201 floor).
- **Magnitude-proxy hypothesis rejected.** Causal joint regression: count b=−0.068 (t=−5.3) survives while `dsig` goes to +0.022 (t=+1.7, wrong/momentum sign) on EUR; count b=−0.033 (t=−2.6) survives, dsig ns on GBP. Signflip null confirms the count coefficient is 5.8σ (EUR) / 2.8σ (GBP) outside the null — not a nested/overlapping-event artifact.
- **Continuous refinement:** max-bar share (concentration) is the single best predictor and the continuous form of count (corr(k, max-share) = −0.85). Univariate t=−4.6 (EUR) / −2.4 (GBP), beating integer count on EUR. Per-bar move size is irrelevant (t≈0). Monotone quintile: even grind (share≈0.47) reverts +0.17 pip; single-bar lunge (share=1.0) → −0.03 (EUR) / −0.11 (GBP) momentum.
- EUR/GBP character split: GBP's persistence effect is real in sign/monotonicity but much weaker and more entangled with plain magnitude in the regression.
