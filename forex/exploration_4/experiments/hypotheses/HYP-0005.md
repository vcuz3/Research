## 1. Why this axis, first and alone

The run-book (§5) puts **displacement depth `|z_slot|` first and alone**: prior FX work found
depth a *near-sufficient statistic* for this z-fade family (`fx-conviction-score-and-model-nogo`
in LEARNINGS: every conditioner tested was redundant with `|z_twap|` depth). So depth is not a
competing overlay — it is the **benchmark curve every later overlay (vol, cross-pair, session,
exit-horizon) must beat at matched count**. EXP-0005's job is to build that curve on the frozen
book and decide whether depth *itself* rescues the book.

## 2. Mechanism

Deeper standardized displacements should revert more reliably: a larger `|z_slot|` means price
is further from its same-slot norm, so the anchor (pre-displacement level) is both further away
(a larger anchor-fill payoff) and, if reversion is real, more likely to be reached. The
competing mechanical story is that deeper `|z_slot|` just means a larger `σ_slot`, which changes
the cost and the guard geometry rather than the reversion — which is exactly why the decision is
read in **R units** and **net of the σ-scaled cost**, not in pips.

## 3. Exact change (overlay on the frozen book — entry NOT changed)

- Base book: the frozen EXP-0004 **stateful, guarded-anchor, delay-1** book, reconstructed by
  importing `_run_stage_b` (identical signals, no-entry rule, cost, non-overlap). Entry stays
  `|z_slot| ≥ 2.0` first crossing; **the overlay never changes the entry.**
- Overlay = a **depth veto**: keep only book-eligible trades with `|z_slot| ≥ t`, then
  **re-apply the one-position non-overlap** (Rule 13 / Stage-B F1: vetoing shallow trades frees
  occupancy, so the stateful book must be recomputed, never filtered post-hoc).
- Sweep `t` on a fine grid from the entry floor 2.0 upward (step 0.05), plus depth quantile
  buckets for readability. `t = 2.0` reproduces the base book exactly (a required parity check).

## 4. Primary metric and decision

**Primary:** per-signal **mean net R_slot** (base cost) on the **re-non-overlapped stateful
book** at each depth threshold, with a UTC-day cluster-robust 95% CI and the per-threshold
trade count printed beside it. Gross R_slot, R_abs and pips reported alongside; consumed
history only for the decision.

**Depth is ACCEPTED as a rescue** only if some threshold at a **deployable count** (≥ ~2,000
consumed trades, ≥ ~2 pairs contributing) has **net R_slot CI strictly > 0** *and* beats the
base book's net at matched count. **Depth is REJECTED as a rescue** if net stays ≤ 0 (CI
includes or is below 0) at every threshold. Either way the **gross depth-response curve is
retained as the Stage-C benchmark**.

**Gated null (my `gate-nullc-on-success-metric` rule):** the claim-matched null is only spent
if the primary metric first clears — i.e. only if some depth threshold shows net CI > 0. If it
does, run a **depth-permutation null**: permute `|z_slot|` across trades within (era, σ_slot
quintile) strata, rebuild the frontier over repeated draws, and compare the real selected-max
net to the null distribution of maxima (selection-aware, since a threshold was searched). If
the primary does not clear, the null is unnecessary and that is stated.

## 5. Controls / diagnostics in the same pass

- **Matched-count direct benchmark:** the depth curve *is* the benchmark; report it as a
  (count, mean-R) lookup so later overlays can be scored as excess over it at equal count.
  Never interpolate a frontier for a matched-count claim — read the swept grid directly.
- **Per-bucket counts beside every stat** (reject a comparison if counts move unexpectedly).
- **Mechanism decomposition:** anchor-fill rate, timeout rate, mean gross pips and mean σ_slot
  by depth bucket — to see whether deeper `|z|` raises the fill/payoff or merely the σ (cost).
- **Both risk units** (R_slot sizing, R_abs yardstick); gross and net; breakeven/rebate pip.
- **`t = 2.0` parity** with the frozen EXP-0004 book (same n, same mean) — a machinery check.
- 2024+ holdout read once at the end, and only if the consumed decision is made first.

## 6. What this run cannot do

- It cannot make a sub-cost gross edge deployable; if depth orders gross R but net stays
  negative, depth is exhausted as a rescue (expected per the honest prior, run-book §7).
- It cannot rehabilitate the ruler: any positive read is conditional on EXP-0004 surviving
  re-verification and on the Stage-A repairs.
- Midpoint OHLC only; cost is modelled; the guarded fill is a model. 2024+ stays sealed until
  the end.
